## ស្ថានភាព

មុនស្នើគម្រោង អ្នកត្រូវបញ្ជាក់ថាហេតុអ្វីអ្នកជ្រើសផ្កាយរណបជាក់លាក់មួយ។ លំហាត់នេះឲ្យអ្នកវាស់ការសម្របសម្រួលដោយខ្លួនឯង ដោយប្រៀបធៀបទំហំឯកសារ និងចំនួនក្រឡានៃរូបភាពដូចគ្នា នៅគុណភាពផ្សេងៗ។

## គោលបំណង

- វាស់ទំនាក់ទំនងរវាងទំហំក្រឡា និងចំនួនក្រឡា/ទំហំឯកសារ។
- បង្កើតកំណែគុណភាពទាបពីរូបភាពគុណភាពខ្ពស់ ដើម្បីមើលឥទ្ធិពលដោយផ្ទាល់។
- ប្រៀបធៀបចំនួនកម្រិតតម្លៃរវាង ៨ ប៊ីត និងកម្រិតទាបជាង។
- សរសេរតារាងតុល្យភាពគុណភាពសម្រាប់គម្រោងជាក់ស្ដែងមួយ។

## សកម្មភាពទី១៖ Resample ក្រឡា · ២៥ នាទី

1. យកក្រុមរលក B4 (១០ ម) ហើយ **Warp (Reproject)** ជាមួយ Output resolution `30` `60` និង `100` ម (Resampling **Average**) → `b4_30.tif` `b4_60.tif` `b4_100.tif`។
2. ធ្វើតារាង៖

    | ក្រឡា | ចំនួនក្រឡា | ទំហំឯកសារ (KB) |
    |---|---:|---:|
    | ១០ ម (ដើម) | | |
    | ៣០ ម | | |
    | ៦០ ម | | |
    | ១០០ ម | | |

3. គណនាសមាមាត្រ៖ ចំនួនក្រឡានៅ ១០ ម ÷ ចំនួនក្រឡានៅ ១០០ ម។ តើវាស្របនឹងច្បាប់ការ៉េ (១០០÷១០)² ដែរឬទេ?
4. បង្ហាញ B4 ដើម និង B4_100m ក្បែរគ្នា។ រកព្រំស្រែមួយ ដែលមើលឃើញច្បាស់នៅ ១០ ម ប៉ុន្តែបាត់នៅ ១០០ ម។

## សកម្មភាពទី២៖ បន្ថយកម្រិតប៊ីត · ២០ នាទី

1. **Raster Calculator**៖ បង្កើតកំណែ ៤ ប៊ីត (១៦ កម្រិត) ពី B4៖

    ```text
    round("B4@1" / 10000 * 15) / 15 * 10000
    ```

2. ដាក់ទាំងពីរ (ដើម និង ៤ ប៊ីត) ក្នុងបន្សំពណ៌ពិត។ សង្កេតឥទ្ធិពល «banding» (ស្រទាប់ពណ៌ឃើញច្បាស់ជំនួសឲ្យបន្តរលោង)។
3. គណនា NDVI ពីកំណែ ៤ ប៊ីត និងកំណែដើម (១២ ប៊ីត) លើគំរូ ១០ ចំណុច។ ប្រៀបធៀបភាពខុសគ្នា។

## សកម្មភាពទី៣៖ ស្ពិចត្រាល់ ធៀបនឹង លំហ · ២០ នាទី

1. ប្រៀបធៀបលេខបញ្ជាក់ផ្លូវការនៃ Sentinel-2 (១៣ ក្រុមរលក · ១០–៦០ ម) និង Landsat 8 (១១ ក្រុមរលក · ១៥–១០០ ម)។
2. គណនាផ្ទៃដីដែលគ្របដណ្ដប់ដោយក្រឡាមួយ (ម²) សម្រាប់ក្រុមរលកលម្អិតបំផុតរបស់នីមួយៗ។
3. សរសេរ ២ ប្រយោគ៖ តើផ្កាយរណបមួយណាផ្ដល់ព័ត៌មានស្ពិចត្រាល់ច្រើនជាងក្នុងផ្ទៃដីតូចជាង?

## សកម្មភាពទី៤៖ ពេលវេលា ធៀបនឹង លំហ · ១៥ នាទី
