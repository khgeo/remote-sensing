## ស្ថានភាព

អ្នកនឹងប្រៀបធៀបរូបភាពតំបន់សិក្សារបស់អ្នក ពីរឆ្នាំខុសគ្នា ដោយវិធីទាំងពីរដែលបានសិក្សា រួចសាងសង់ស៊េរីពេលវេលា NDVI ខ្លីមួយ ពីរូបភាពច្រើនចំណុច។

## គោលបំណង

- ទាញយករូបភាព Sentinel-2 ពីរឆ្នាំខុសគ្នា ខែដូចគ្នា។
- អនុវត្ត Image Differencing និងជ្រើសកម្រិតកំណត់។
- អនុវត្ត Post-classification Comparison និងសាងសង់តារាងផ្លាស់ប្ដូរ។
- សាងសង់ស៊េរីពេលវេលា NDVI ពីរូបភាពយ៉ាងតិចប្រាំចំណុច។

## សកម្មភាពទី១៖ ពិនិត្យលក្ខខណ្ឌជាមុន · ១៥ នាទី

1. បើក `SHV_2015_S2.tif` និង `SHV_2021_S2.tif` ជាបន្សំពណ៌ពិត (ស្រទាប់ ៤-៣-២) ដោយកំណត់ **Min/Max ដូចគ្នាដោយដៃ** (ឧ. ០ ដល់ ២ ០០០) សម្រាប់ទាំងពីរ។
2. ពិនិត្យ CRS ទំហំក្រឡា និងវិសាលភាព ដូចគ្នាទាំងពីរ (Layer Properties → Information)។
3. ប្រើ **Map Swipe** ដើម្បីរកតំបន់បីកន្លែងដែលផ្លាស់ប្ដូរច្បាស់។ ថតរូបអេក្រង់។

## សកម្មភាពទី២៖ Image Differencing · ២៥ នាទី

1. **Raster Calculator** សម្រាប់ឆ្នាំនីមួយៗ៖

    ```text
    ("SHV_2015_S2@5" - "SHV_2015_S2@4") / ("SHV_2015_S2@5" + "SHV_2015_S2@4")
    ```

    → `ndvi_2015.tif` និង `ndvi_2021.tif` (Float32)។

2. `"ndvi_2021@1" - "ndvi_2015@1"` → `ndvi_diff.tif`។
3. សាកល្បងកម្រិតកំណត់ −០,១៥ · −០,២ · −០,៣ (`"ndvi_diff@1" < -0.2`)។ ថតរូបអេក្រង់នីមួយៗ។
4. គណនាផ្ទៃបាត់បង់រុក្ខជាតិ (ហ.ត)៖ **Raster → Analysis → Raster Layer Unique Values Report** លើស្រទាប់ ០/១ រួចគុណចំនួនក្រឡានឹងផ្ទៃក្រឡា។ ចំណាំ៖ ក្រឡាជា ដឺក្រេ (EPSG:4326) ដូច្នេះត្រូវ **Warp (Reproject)** ទៅ EPSG:32648 ជាមុន ដើម្បីគណនាផ្ទៃជាម៉ែត្រ។

## សកម្មភាពទី៣៖ Post-classification Comparison · ៣០ នាទី

1. ចាត់ថ្នាក់រូបភាពទាំងពីរឆ្នាំ ដោយ SCP (ចម្ងាយអប្បបរមា) ជាមួយថ្នាក់ដូចគ្នា៖ ព្រៃឈើ · ដំណាំ/ស្មៅ · តំបន់សាងសង់ · ដីទទេ · ទឹក → `lc_2015.tif` និង `lc_2021.tif`។
2. **Raster Calculator** បង្កើតលេខកូដបន្សំ៖ `"lc_2015@1" * 10 + "lc_2021@1"` (ឧ. ១៤ = ព្រៃឈើ→ដីទទេ)។
3. អានតារាងផ្លាស់ប្ដូរ (Unique Values Report) ហើយគណនាផ្ទៃ (ហ.ត) សម្រាប់ការផ្លាស់ប្ដូរសំខាន់ៗ។

## សកម្មភាពទី៥៖ ស៊េរីពេលវេលា NDVI (រូបភាពដែលអ្នកទាញយក) · ២០ នាទី

1. ទាញយករូបភាព Sentinel-2 បន្ថែម ៣ ចំណុចកាលបរិច្ឆេទ (សរុបយ៉ាងតិច ៥ ជាមួយពីរពីមុន) ក្នុងឆ្នាំតែមួយ ចែកគ្នាតាមរដូវ។
2. គណនា NDVI មធ្យមលើតំបន់តូចមួយ (ឧ. ក្បាលស្រែមួយ) សម្រាប់រូបភាពនីមួយៗ (**Zonal Statistics**)។
3. គូសក្រាបនៅក្នុង Excel៖ អ័ក្ស X = កាលបរិច្ឆេទ · អ័ក្ស Y = NDVI មធ្យម។ ប្រៀបធៀបរាងខ្សែកោងរបស់អ្នក ជាមួយពិសោធន៍ដេរិកកម្ម។
