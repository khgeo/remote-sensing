# លំហាត់ទី៦៖ ស្វែងរក និងចាត់ចែងរូបភាពសម្រាប់ស៊េរីពេលវេលា

## ស្ថានភាព

អ្នកត្រូវរៀបចំគំរូរូបភាព ១២ សន្លឹក (មួយសន្លឹកក្នុងមួយខែ) លើតំបន់តែមួយ សម្រាប់ការវិភាគស៊េរីពេលវេលានាពេលក្រោយ ([មេរៀនទី១៤](../lessons/lesson-14.md))។ លំហាត់នេះហ្វឹកហ្វឺនជំនាញស្វែងរក និងចាត់ចែងទិន្នន័យ។

## គោលបំណង

- ស្វែងរករូបភាព Sentinel-2 ជាប្រព័ន្ធ តាមខែ។
- កត់ត្រា log ពេញលេញនៃរូបភាពដែលបានពិនិត្យ។
- ចាត់ចែងឯកសារតាមរចនាសម្ព័ន្ធថតដែលអាចប្រើឡើងវិញបាន។
- ស្វែងរក Landsat តាម Path/Row សម្រាប់តំបន់ដដែល។

## ឯកសារដែលប្រើ

- តំបន់សិក្សា (ខេត្តរបស់អ្នក ឬតូចជាងនេះ)

## សកម្មភាពទី១៖ កំណត់ tile និង path/row · ១៥ នាទី

1. ក្នុង Copernicus Browser រុករកទៅតំបន់របស់អ្នក ហើយអានលេខ MGRS tile ដែលបង្ហាញ (ឧ. `T48PVU`)។
2. ក្នុង USGS EarthExplorer ប្រើ **Path/Row** search ដើម្បីរកលេខ Path និង Row គ្របដណ្ដប់តំបន់ដដែល។
3. កត់ត្រាទាំងពីរនេះក្នុងឯកសារ `README.txt` របស់គម្រោង ដើម្បីកុំចាំបាច់ស្វែងរកម្ដងទៀត។

## សកម្មភាពទី២៖ ស្វែងរកជាប្រព័ន្ធ · ៤០ នាទី

សម្រាប់ខែនីមួយៗក្នុងឆ្នាំកន្លងមក (ឬឆ្នាំដែលមានទិន្នន័យគ្រប់គ្រាន់)៖

1. ត្រង Sentinel-2 L2A តាម tile ដែលបានកត់ត្រា · ខែនោះ · ពពក < ៣០%។
2. ជ្រើសរូបភាពដែលមានពពកតិចបំផុតលើ **តំបន់សិក្សា** (មិនមែនតំបន់ tile ទាំងមូល)។ ត្រូវពិនិត្យ preview ជានិច្ច។
3. កត់ត្រាក្នុងតារាង log៖

    | ខែ | ID រូបភាព | ថ្ងៃថត | ពពក % លើតំបន់សិក្សា | R-number | មតិ |
    |---|---|---|---|---|---|
    | មករា | | | | | |
    | កុម្ភៈ | | | | | |
    | ... | | | | | |

4. សម្រាប់ខែណាដែលគ្មានរូបភាពគ្មានពពក សរសេរ «គ្មានទិន្នន័យប្រើការបាន» ជំនួសឲ្យទុកទទេ។

## សកម្មភាពទី៣៖ ចាត់ចែងទិន្នន័យ · ២០ នាទី

1. បង្កើតរចនាសម្ព័ន្ធថត៖

    ```text
    project/
      raw/S2/YYYY-MM-DD_TXXXXX/
      raw/Landsat/YYYY-MM-DD_PxxxRxx/
      processed/
      logs/imagery_log.csv
    ```

2. ទាញយករូបភាពយ៉ាងតិចបួនខែ (រាយប្រហែលគ្នាតាមឆ្នាំ) តាមរចនាសម្ព័ន្ធនេះ។
3. រក្សា `imagery_log.csv` ដែលមានជួរឈរដូចតារាងខាងលើ បូកនឹង **path ឯកសារ**។

## សកម្មភាពទី៤៖ ប្រៀបធៀបជាមួយ Landsat · ១៥ នាទី

សម្រាប់ខែមួយក្នុងចំណោមនោះ ស្វែងរក Landsat 8/9 Collection 2 Level-2 តាម Path/Row ដែលបានកត់ត្រា ក្នុងចន្លោះកាលបរិច្ឆេទជិតគ្នា។ បន្ថែមទៅ log ជាជួរដេកបន្ថែម។

## សកម្មភាពទី៥៖ ការវាយតម្លៃភាពមានទិន្នន័យ · ១០ នាទី

គូសក្រាបសាមញ្ញ (Excel) បង្ហាញភាគរយពពកតាមខែ។ សរសេរ ២ ប្រយោគ៖ ខែណាដែលការស្វែងរកពិបាកបំផុត និងហេតុអ្វី។

## លទ្ធផលត្រូវប្រគល់
