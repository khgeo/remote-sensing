# លំហាត់ទី៨៖ ត្រួតពិនិត្យភាពត្រឹមត្រូវធរណីមាត្រ និងផ្សំរូបភាព

!!! info "ព័ត៌មានលំហាត់"
    **មេរៀនពាក់ព័ន្ធ៖** [មេរៀនទី៨៖ ការកែតម្រូវធរណីមាត្រ និងការរួមផ្សំរូបភាព](../lessons/lesson-08.md)
    **ការអនុវត្តដោយខ្លួនឯង** · QGIS 3.34 LTR · ប្រហែល ១០០ នាទី

## ស្ថានភាព

អ្នកត្រូវផ្ទៀងផ្ទាត់ថារូបភាព Sentinel-2 របស់អ្នកត្រូវនឹងទីតាំងពិត ហើយផ្សំរូបភាពពីរ tile ជាមួយគ្នា សម្រាប់តំបន់សិក្សាដែលធំជាង tile មួយ។

## គោលបំណង

- ផ្ទៀងផ្ទាត់ភាពត្រឹមត្រូវធរណីមាត្រ ដោយប្រៀបធៀបនឹងស្រទាប់វ៉ិចទ័រ។
- វាស់ភាពមិនស៊ីគ្នារវាងរូបភាព និងផែនទីមូលដ្ឋាន។
- ផ្សំ (mosaic) tile ពីរជាមួយគ្នា ដោយប្រើ Virtual Raster។
- កែសម្រួលភាពខុសគ្នានៃពណ៌រវាងសន្លឹក។

## ឯកសារដែលប្រើ

- រូបភាព Sentinel-2 L2A ពីលំហាត់មុន
- ស្រទាប់ `Kh_Main_Roads_MPWT2014` ពីសំណុំទិន្នន័យ `Cambodia`
- (ស្រេចចិត្ត) tile ទីពីរដែលជាប់នឹងតំបន់សិក្សារបស់អ្នក

## សកម្មភាពទី១៖ ផ្ទៀងផ្ទាត់ជាមួយស្រទាប់វ៉ិចទ័រ · ២៥ នាទី

1. បន្ថែម `Kh_Main_Roads_MPWT2014` លើរូបភាព Sentinel-2 ពណ៌ពិត។
2. ពង្រីកទៅចំណុចប្រសព្វផ្លូវធំៗ ៣ កន្លែងក្នុងតំបន់សិក្សា។
3. សម្រាប់នីមួយៗ វាស់ចម្ងាយរវាងខ្សែផ្លូវលើវ៉ិចទ័រ និងផ្លូវលើរូបភាព (Measure Line)។ កត់ត្រាក្នុងតារាង៖

    | ចំណុច | ចម្ងាយមិនស៊ីគ្នា (ម) | ទីតាំង (ភ្នំ/រាប) |
    |---|---:|---|
    | ១ | | |
    | ២ | | |
    | ៣ | | |

4. តើភាពមិនស៊ីគ្នាធំជាងនៅតំបន់ភ្នំ ឬតំបន់រាបស្មើ? តើនេះស្របនឹងទ្រឹស្ដីជម្រាលភូមិសាស្ត្រឬទេ?

## សកម្មភាពទី២៖ បង្កើត GCP ផ្ទាល់ខ្លួន · ២៥ នាទី

1. ប្រើ **Georeferencer** (Raster → Georeferencer) លើរូបភាព។
2. ដាក់ចំណុច GCP ៦ ចំណុច នៅចំណុចប្រសព្វផ្លូវច្បាស់ៗ ដោយចុចលើផែនទីមូលដ្ឋាន OpenStreetMap ព្រមគ្នា។
3. អាន **Residual (Total RMSE)** ដែល Georeferencer បង្ហាញ។
4. លុបចំណុចមួយដែលមាន residual ខ្ពស់បំផុត ហើយសង្កេតថា RMSE សរុបប្ដូរយ៉ាងណា។

**សំណួរ**៖ ហេតុអ្វីការលុបចំណុចខ្លះ អាចកាត់បន្ថយ RMSE សរុប ប៉ុន្តែមិនតែងតែជាការសម្រេចចិត្តល្អ?

## សកម្មភាពទី៣៖ ផ្សំ tile ពីរ (ឬតំបន់រង) · ២៥ នាទី

1. បើមានតែ tile មួយ បំបែកវាជាពីរផ្នែក (ខាងឆ្វេង/ខាងស្ដាំ) ដោយប្រើ Clip ដើម្បីក្លែងធ្វើដូចជាមាន tile ពីរ។
2. ប្ដូរ Contrast enhancement របស់ផ្នែកមួយឲ្យខុសពីមួយទៀត (ក្លែងធ្វើដូចជាថតខុសថ្ងៃ)។
3. **Raster → Miscellaneous → Build Virtual Raster** ផ្សំទាំងពីរ។
4. សង្កេតបន្ទាត់ព្រំដែនរវាងផ្នែកទាំងពីរ។

## សកម្មភាពទី៤៖ កែសម្រួលព្រំដែន · ១៥ នាទី

<div class="sim" data-sim="rs-mosaic"></div>

1. កំណត់ Contrast enhancement ឲ្យដូចគ្នាទាំងពីរផ្នែក (ដូចក្នុងពិសោធន៍) ហើយផ្សំម្ដងទៀត។
2. ប្រៀបធៀបជាមួយកំណែដើម។ តើព្រំដែនលេចធ្លោតិចជាងទេ?

## សកម្មភាពទី៥៖ សេចក្ដីសន្និដ្ឋាន · ១០ នាទី

សរសេរ ៤ ប្រយោគ៖ កម្រិតភាពត្រឹមត្រូវធរណីមាត្រនៃរូបភាពរបស់អ្នក (ជា ម) · ថាតើវាគ្រប់គ្រាន់សម្រាប់ការវិភាគដែលអ្នកគ្រោងធ្វើ · និងអ្វីដែលអ្នកនឹងធ្វើផ្សេង បើត្រូវការភាពត្រឹមត្រូវខ្ពស់ជាង។

## លទ្ធផលត្រូវប្រគល់

- តារាងវាស់ភាពមិនស៊ីគ្នា និងការសន្និដ្ឋាន។
- លទ្ធផល Georeferencer (RMSE) និងរូបថតអេក្រង់។
- Virtual raster ដែលផ្សំរួច ព្រមទាំងកំណែមុន/ក្រោយកែសម្រួលពណ៌។
