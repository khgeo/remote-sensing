# លំហាត់ទី១២៖ បណ្ដុះបណ្ដាល និងចាត់ថ្នាក់ដោយប្រើគំរូ

!!! info "ព័ត៌មានលំហាត់"
    **មេរៀនពាក់ព័ន្ធ៖** [មេរៀនទី១២៖ ការចាត់ថ្នាក់មានការណែនាំ](../lessons/lesson-12.md)
    **ការអនុវត្តដោយខ្លួនឯង** · QGIS 3.34 LTR · ប្រហែល ១១០ នាទី

## ស្ថានភាព

អ្នកនឹងបង្កើតគំរូបណ្ដុះបណ្ដាលពីរូបភាព ហើយប្រើវាដើម្បីចាត់ថ្នាក់តំបន់សិក្សាទាំងមូលដោយប្រើ SCP។ លទ្ធផលនឹងត្រូវប្រៀបធៀបជាមួយលទ្ធផលគ្មានការណែនាំពីលំហាត់មុន។

## គោលបំណង

- បង្កើតគំរូបណ្ដុះបណ្ដាលប្រកបដោយគុណភាពសម្រាប់ថ្នាក់ប្រាំ។
- ដំណើរការចម្ងាយអប្បបរមា ឬ Maximum Likelihood ក្នុង SCP។
- ប្រៀបធៀបជាមួយលទ្ធផលគ្មានការណែនាំ។
- ញែកគំរូជាសំណុំបណ្ដុះបណ្ដាល និងសំណុំផ្ទៀងផ្ទាត់ឯករាជ្យ។

## ឯកសារដែលប្រើ

- រូបភាព Sentinel-2 L2A ពីលំហាត់មុន
- `landcover_unsupervised.tif` ពី[លំហាត់ទី១១](lab-11.md) (សម្រាប់ប្រៀបធៀប)

## សកម្មភាពទី១៖ បង្កើតគំរូបណ្ដុះបណ្ដាល · ៣៥ នាទី

1. ក្នុង SCP បើក **Training input** → បង្កើត Training input ថ្មី (GeoPackage)។
2. សម្រាប់ថ្នាក់នីមួយៗ (ទឹក ព្រៃឈើ ស្រែ សំណង់ ដីទទេ) បង្កើត **Macroclass ID** និងគូសពហុកោណតូចៗ ២០ ទៅ ៣០ នៅលើតំបន់ដែលច្បាស់ (មើលបន្សំពណ៌សន្មត ជំនួយ)។
3. ធីក **Preview** ដើម្បីមើលហត្ថលេខាស្ពិចត្រាល់នៃគំរូនីមួយៗ ក្នុងផ្ទាំង Spectral Signature Plot របស់ SCP។ ប្រៀបធៀបនឹងរូបរាងក្រាបក្នុង[មេរៀនទី៣](../lessons/lesson-03.md)។

!!! warning "ភាពបរិសុទ្ធ"
    ជៀសវាងគូសពហុកោណឆ្លងកាត់ព្រំរវាងថ្នាក់។ បើឃើញក្រាបហត្ថលេខាមានរាងចម្លែក ឬប្រែប្រួលខ្លាំងពេក ត្រូវត្រួតពិនិត្យគំរូនោះឡើងវិញ។

## សកម្មភាពទី២៖ ចាត់ថ្នាក់ · ២៥ នាទី

1. **SCP → Band processing → Classification**៖ ជ្រើសក្បួនដោះស្រាយ **Minimum Distance**។
2. ដំណើរការលើតំបន់សិក្សាទាំងមូល → `landcover_supervised.tif`។
3. ធ្វើម្ដងទៀតជាមួយ **Maximum Likelihood** → `landcover_ml.tif`។ ប្រៀបធៀបលទ្ធផលទាំងពីរដោយភ្នែក។

## សកម្មភាពទី៣៖ ប្រៀបធៀបជាមួយគ្មានការណែនាំ · ២០ នាទី

1. ដាក់ `landcover_unsupervised.tif` និង `landcover_supervised.tif` ក្បែរគ្នា ជាមួយពណ៌ដូចគ្នាសម្រាប់ថ្នាក់ដូចគ្នា។
2. រកតំបន់បីកន្លែងដែលលទ្ធផលទាំងពីរខុសគ្នា។ ថតរូបអេក្រង់។
3. ប្រើបន្សំពណ៌ពិត ដើម្បីវិនិច្ឆ័យថាមួយណាទំនងជាត្រឹមត្រូវជាងនៅតំបន់នីមួយៗ។

## សកម្មភាពទី៤៖ ញែកគំរូបណ្ដុះបណ្ដាល · ១៥ នាទី

1. ត្រឡប់ទៅ Training input របស់អ្នក។ **បែងចែកជាពីរ**៖ ៧០% សម្រាប់បណ្ដុះបណ្ដាល ៣០% សម្រាប់ផ្ទៀងផ្ទាត់ (ធ្វើដោយដៃ ឬចម្លងឯកសារ រួចលុបជួរខ្លះចេញ)។
2. រក្សាទុកជាពីរឯកសារដាច់ដោយឡែក៖ `training_70.gpkg` និង `validation_30.gpkg`។ ឯកសារទីពីរនេះនឹងប្រើក្នុង[លំហាត់ទី១៣](lab-13.md)។

## សកម្មភាពទី៥៖ ការសន្និដ្ឋាន · ១៥ នាទី

សរសេរ ៥ ប្រយោគ៖ ភាពខុសគ្នារវាងលទ្ធផលមានការណែនាំ និងគ្មានការណែនាំ · ថាតើវិធីមានការណែនាំមើលទៅត្រឹមត្រូវជាងដោយភ្នែកដែរឬទេ · និងហេតុអ្វី។

## លទ្ធផលត្រូវប្រគល់

- `landcover_supervised.tif` និង `landcover_ml.tif`។
- `training_70.gpkg` និង `validation_30.gpkg`។
