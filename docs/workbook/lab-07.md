# លំហាត់ទី៧៖ បម្លែង DN ទៅការឆ្លុះបញ្ចាំង និងកែតម្រូវបរិយាកាស

!!! info "ព័ត៌មានលំហាត់"
    **មេរៀនពាក់ព័ន្ធ៖** [មេរៀនទី៧៖ ការកែតម្រូវរ៉ាដ្យូម៉ែត្រ និងបរិយាកាស](../lessons/lesson-07.md)
    **ការអនុវត្តដោយខ្លួនឯង** · QGIS 3.34 LTR · ប្រហែល ១១០ នាទី

## ស្ថានភាព

អ្នកនឹងអនុវត្តការគណនាកែតម្រូវដោយដៃ ដើម្បីយល់ថាតើផលិតផលកម្រិត L2A ធ្វើអ្វីខ្លះនៅពីក្រោយឆាក។ បន្ទាប់មក អ្នកនឹងធ្វើ Dark Object Subtraction ដោយខ្លួនឯង លើរូបភាព L1C។

## គោលបំណង

- បម្លែង DN ទៅជាការឆ្លុះបញ្ចាំង TOA ដោយប្រើ Raster Calculator។
- អនុវត្ត Dark Object Subtraction ដោយដៃ។
- ប្រៀបធៀបលទ្ធផលរបស់ខ្លួនឯង ជាមួយផលិតផល L2A ផ្លូវការ។
- កំណត់ស្នាមឆ្នូត និងស្រមោលពពកលើរូបភាពពិត។

## ឯកសារដែលប្រើ

- Sentinel-2 **L1C** និង **L2A** ដដែលនឹង[លំហាត់ទី២](lab-02.md)

## សកម្មភាពទី១៖ បម្លែង DN ទៅ TOA · ២០ នាទី

1. លើ B4 នៃ L1C **Raster Calculator**៖

    ```text
    ("B4@1" - 1000) / 10000
    ```

    (សម្រាប់ processing baseline ចាស់ជាង 04.00 មិនចាំបាច់ដក ១០០០ ទេ · ពិនិត្យមេតាទិន្នន័យ) → `b4_toa.tif`

2. ធ្វើដូចគ្នាសម្រាប់ B3 B2 និង B8។
3. បង្កើតបន្សំពណ៌ពិតពី `*_toa.tif` ហើយប្រៀបធៀបជាមួយបន្សំពី DN ឆៅ។ តើមានភាពខុសគ្នាទេ (ក្រៅពីជួរតម្លៃ)?

## សកម្មភាពទី២៖ Dark Object Subtraction ដោយដៃ · ៣៥ នាទី

1. រកតម្លៃអប្បបរមានៃ `b4_toa.tif` (Layer Properties → Histogram ឬ Raster → Analysis → Statistics)។ នេះជាតម្លៃ **object ងងឹតបំផុត** ដែលគួរជាទឹកជ្រៅ ឬស្រមោល។
2. **Raster Calculator**៖

    ```text
    "b4_toa@1" - [តម្លៃអប្បបរមា]
    ```

    → `b4_dos.tif`

3. ធ្វើដូចគ្នាសម្រាប់ B3 B2 B8 (នីមួយៗប្រើតម្លៃអប្បបរមារបស់ខ្លួន)។
4. បង្កើតបន្សំពណ៌ពិតពី `*_dos.tif` ហើយប្រៀបធៀបជាមួយ `*_toa.tif`។ តើមួយណាមើលទៅច្បាស់ជាង?

## សកម្មភាពទី៣៖ ប្រៀបធៀបជាមួយ L2A ផ្លូវការ · ២៥ នាទី

1. យកគំរូចំណុច ១០ ដូចគ្នា (ពី[លំហាត់ទី២](lab-02.md)) ហើយទាញតម្លៃពី `b4_dos.tif` (កំណែផ្ទាល់ខ្លួន) និង B4 នៃ L2A ផ្លូវការ។
2. គូសក្រាបខ្ចាត់ខ្ចាយ (scatter plot) រវាងតម្លៃទាំងពីរក្នុង Excel។ តើវាទាក់ទងគ្នាជិតបន្ទាត់ត្រង់ដែរឬទេ?
3. គណនាភាពខុសគ្នាមធ្យម។ តើវិធី DOS សាមញ្ញរបស់អ្នក ខិតជិត Sen2Cor ផ្លូវការប៉ុនណា?

**សំណួរ**៖ ចុះបើ DOS ខុសខ្លាំង តើអ្វីអាចជាមូលហេតុ? (ពិចារណាថាតើមានទឹកជ្រៅ ឬស្រមោលពិតក្នុងទិដ្ឋភាពដែរឬទេ)

## សកម្មភាពទី៤៖ ការត្រួតពិនិត្យគុណភាព · ២០ នាទី

1. បើករូបភាព L2A ជាបន្សំពណ៌ពិត ហើយពិនិត្យរកបញ្ហា៖ ស្នាមឆ្នូត · ស្រមោលពពក (ប្រើ SCL ជំនួយ) · និងតំបន់ដែលមើលទៅខុសប្រក្រតី។
2. ថតរូបអេក្រង់នៃបញ្ហាណាមួយដែលអ្នករកឃើញ ព្រមទាំងកូអរដោនេ។ បើគ្មានបញ្ហា សរសេរបញ្ជាក់ថាបានពិនិត្យ និងគ្មានរកឃើញ។
3. បើអាចរក បើករូបភាព Landsat 7 ណាមួយក្រោយឆ្នាំ ២០០៣ (ស្វែងរកក្នុង EarthExplorer) ដើម្បីមើលឥទ្ធិពល SLC-off ដោយផ្ទាល់ភ្នែក។

## សកម្មភាពទី៥៖ សេចក្ដីសន្និដ្ឋាន · ១០ នាទី

សរសេរ ៥ ប្រយោគ៖ ជំហានកែតម្រូវមួយណាដែលអ្នកបានធ្វើដោយដៃ · លទ្ធផលប្រៀបធៀបនឹង L2A ផ្លូវការ · និងអ្វីដែលអ្នកបានយល់អំពីដែនកំណត់នៃ DOS។

## លទ្ធផលត្រូវប្រគល់

- `*_toa.tif` និង `*_dos.tif` សម្រាប់ក្រុមរលកទាំងបួន។
- ក្រាបខ្ចាត់ខ្ចាយប្រៀបធៀប DOS ផ្ទាល់ខ្លួន និង L2A ផ្លូវការ។
- កំណត់ត្រាការត្រួតពិនិត្យគុណភាព និងសេចក្ដីសន្និដ្ឋាន។
