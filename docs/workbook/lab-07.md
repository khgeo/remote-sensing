# លំហាត់ទី៧៖ បម្លែង DN ទៅការចាំងផ្លាត និងកែតម្រូវបរិយាកាស

!!! info "ព័ត៌មានលំហាត់"
    **មេរៀនពាក់ព័ន្ធ៖** [មេរៀនទី៧៖ ការកែតម្រូវរ៉ាដ្យូម៉ែត្រ និងបរិយាកាស](../lessons/lesson-07.md)
    **ការអនុវត្តដោយខ្លួនឯង** · QGIS 3.34 LTR · ប្រហែល ១១០ នាទី

## ស្ថានភាព

អ្នកនឹងអនុវត្តការកែតម្រូវដោយដៃលើ **រូបភាព Landsat 8 ពិតលើភ្នំពេញ** (២០១៩-០២-១១) ដោយប្រើមេគុណពិតពីឯកសារ MTL។ នេះជាការងារដែលផលិតផលកម្រិត Level-2 ធ្វើនៅពីក្រោយឆាក។ បន្ទាប់មក អ្នកនឹងធ្វើ Dark Object Subtraction ហើយពិនិត្យថាតម្លៃ និង NDVI ប្ដូរយ៉ាងណា។

## គោលបំណង

- អានមេគុណក្រិតពីឯកសារ MTL ពិត។
- បម្លែង DN ទៅជាការចាំងផ្លាត TOA និងកែមុំព្រះអាទិត្យ ដោយ Raster Calculator។
- អនុវត្ត Dark Object Subtraction ដោយដៃ។
- ប្រៀបធៀប NDVI ដែលគណនាពី DN ពី TOA និងពី DOS។

## ឯកសារដែលប្រើ

- (ជម្រើស) Sentinel-2 L1C និង L2A ពី[លំហាត់ទី២](lab-02.md) សម្រាប់ប្រៀបធៀបបន្ថែម

## សកម្មភាពទី១៖ អានឯកសារ MTL · ១៥ នាទី

បើក `..._MTL.txt` ដោយកម្មវិធីអត្ថបទ ហើយរកតម្លៃទាំងនេះ៖

| វាល | តម្លៃ |
|---|---|
| `DATE_ACQUIRED` · `SCENE_CENTER_TIME` | |
| `CLOUD_COVER` | |
| `SUN_ELEVATION` | |
| `REFLECTANCE_MULT_BAND_4` · `REFLECTANCE_ADD_BAND_4` | |
| `REFLECTANCE_MULT_BAND_5` · `REFLECTANCE_ADD_BAND_5` | |

## សកម្មភាពទី២៖ DN → TOA → កែមុំព្រះអាទិត្យ · ២៥ នាទី

1. បើក `L8_B4.tif` និង `L8_B5.tif` ក្នុង QGIS។ ពិនិត្យថាតម្លៃជាចំនួនគត់ (DN) ប្រហែល ៦ ០០០ ដល់ ៣០ ០០០។
2. **Raster Calculator** (Output data type = Float32)៖

    ```text
    ("L8_B4@1" * 0.00002 - 0.1) / sin(51.56434261 * pi() / 180)
    ```

    → `b4_toa.tif`។ ធ្វើដូចគ្នាសម្រាប់ B2 B3 B5 B6 B7។

3. ពិនិត្យតម្លៃលើទន្លេមេគង្គ ដីទទេ និងចម្ការដើមឈើ ដោយ **Identify Features**។ បំពេញតារាង៖

    | ចំណុច | DN (B4) | TOA (B4) | DN (B5) | TOA (B5) |
    |---|---:|---:|---:|---:|
    | ទន្លេមេគង្គ | | | | |
    | ដើមឈើ | | | | |
    | ដីទទេ | | | | |

## សកម្មភាពទី៣៖ Dark Object Subtraction · ២៥ នាទី

1. រកតម្លៃអប្បបរមានៃ `b4_toa.tif` (**Raster → Analysis → Raster Layer Statistics**)។ ប្រើតម្លៃ percentile ០,១% ជំនួសអប្បបរមាដាច់ខាត បើមានក្រឡាខុសប្រក្រតី។
2. **Raster Calculator**៖ `"b4_toa@1" - [តម្លៃអប្បបរមា]` → `b4_dos.tif`។ ធ្វើដូចគ្នាសម្រាប់ក្រុមរលកផ្សេង។
3. គណនា NDVI បីបែប ហើយប្រៀបធៀបលើចំណុចដដែល៖

    | NDVI ពី | ទន្លេ | ដើមឈើ | ដីទទេ |
    |---|---:|---:|---:|
    | DN ឆៅ | | | |
    | TOA | | | |
    | DOS | | | |

**សំណួរ**៖ ហេតុអ្វី NDVI ពី DN ខុសពី NDVI ពី TOA ទោះប្រើរូបមន្តដូចគ្នា? (ពិចារណាមេគុណ Add = −០,១)

## សកម្មភាពទី៤៖ ការត្រួតពិនិត្យគុណភាព · ២០ នាទី

1. បង្កើតបន្សំពណ៌ពិត (B4-B3-B2) ពី `*_toa.tif` ហើយពិនិត្យរកបញ្ហា៖ ស្នាមឆ្នូត · ពពក ឬស្រមោលពពក (ពពក ០,២៣% តាម MTL) · និងតំបន់ដែលមើលទៅខុសប្រក្រតី។
2. ថតរូបអេក្រង់នៃបញ្ហាណាមួយដែលអ្នករកឃើញ ព្រមទាំងកូអរដោនេ។ បើគ្មានបញ្ហា សរសេរបញ្ជាក់ថាបានពិនិត្យ និងគ្មានរកឃើញ។
3. បើអាចរក បើករូបភាព Landsat 7 ណាមួយក្រោយឆ្នាំ ២០០៣ (ស្វែងរកក្នុង EarthExplorer) ដើម្បីមើលឥទ្ធិពល SLC-off ដោយផ្ទាល់ភ្នែក។

## សកម្មភាពទី៥៖ សេចក្ដីសន្និដ្ឋាន · ១០ នាទី

សរសេរ ៥ ប្រយោគ៖ ជំហានកែតម្រូវដែលអ្នកបានធ្វើដោយដៃ · ភាពខុសគ្នានៃ NDVI រវាង DN TOA និង DOS · និងអ្វីដែលអ្នកបានយល់អំពីដែនកំណត់នៃ DOS (មានក្រឡាងងឹតពិតក្នុងរូបភាពភ្នំពេញឬទេ?)។
