## ស្ថានភាព

អ្នកនឹងគណនាសន្ទស្សន៍ចំនួនប្រាំ លើរូបភាព Sentinel-2 របស់អ្នក ប្រៀបធៀបនឹងគ្នា ហើយវាយតម្លៃថាសន្ទស្សន៍ណាបំពេញភារកិច្ចនីមួយៗបានល្អបំផុត។

## គោលបំណង

- គណនា NDVI NDWI MNDWI NDBI និង BSI ក្នុង Raster Calculator។

- យកគំរូតម្លៃលើថ្នាក់គម្របដីខុសៗគ្នា ហើយប្រៀបធៀបភាពបែងចែក។
- កំណត់សន្ទស្សន៍ណាដែលសមស្របនឹងភារកិច្ចនីមួយៗ។

## ឯកសារដែលប្រើ

- **ទិន្នន័យវគ្គ (ណែនាំ)**៖ Landsat 8 ភ្នំពេញ (TOA ពី[លំហាត់ទី៧](lab-07.md)) · [`RS_Data.zip`](https://github.com/khgeo/remote-sensing/releases/latest/download/RS_Data.zip) → `L8_PhnomPenh_2019` ([ឧបសម្ព័ន្ធ ខ](../appendix/b-imagery-data.md))
- ឬរូបភាព Sentinel-2 L2A ពីលំហាត់មុន (B2 B3 B4 B8 B11)

!!! tip "ឈ្មោះក្រុមរលកតាមឧបករណ៍"
    | តួនាទី | Sentinel-2 | Landsat 8/9 |
    |---|---|---|
    | ខៀវ · បៃតង · ក្រហម | B2 · B3 · B4 | B2 · B3 · B4 |
    | NIR | B8 | B5 |
    | SWIR1 · SWIR2 | B11 · B12 | B6 · B7 |

    បើប្រើទិន្នន័យ Landsat 8 ភ្នំពេញ សូមប្ដូរលេខក្រុមរលកក្នុងរូបមន្ត និងបន្សំពណ៌តាមតារាងនេះ (ឧ. NDVI = (B5 − B4) / (B5 + B4))។

    រូបមន្ត Landsat៖ NDVI `(B5−B4)/(B5+B4)` · NDWI `(B3−B5)/(B3+B5)` · MNDWI `(B3−B6)/(B3+B6)` · NDBI `(B6−B5)/(B6+B5)` · BSI `((B6+B4)−(B5+B2))/((B6+B4)+(B5+B2))`

## សកម្មភាពទី១៖ គណនាសន្ទស្សន៍ប្រាំ · ៣៥ នាទី

ប្រើ **Raster Calculator** សម្រាប់នីមួយៗ (ជំនួស ឈ្មោះស្រទាប់ តាមតម្រូវការ)៖

| សន្ទស្សន៍ | កន្សោម |
|---|---|
| NDVI | `("B8@1" - "B4@1") / ("B8@1" + "B4@1")` |
| NDWI | `("B3@1" - "B8@1") / ("B3@1" + "B8@1")` |
| MNDWI | `("B3@1" - "B11@1") / ("B3@1" + "B11@1")` |
| NDBI | `("B11@1" - "B8@1") / ("B11@1" + "B8@1")` |
| BSI | `(("B11@1"+"B4@1")-("B8@1"+"B2@1")) / (("B11@1"+"B4@1")+("B8@1"+"B2@1"))` |

!!! warning "ប្រភេទទិន្នន័យលទ្ធផល"
    ក្នុងប្រអប់ Raster Calculator ត្រូវប្រាកដថាកំណត់ **Output raster data type = Float32** មិនមែន Int ទេ បើមិនដូច្នោះទេ តម្លៃទសភាគនឹងត្រូវកាត់ចោល។

## សកម្មភាពទី២៖ ដាក់ពណ៌ · ២០ នាទី

1. សម្រាប់ NDVI៖ Singleband pseudocolor · Color ramp «RdYlGn» · Min `-1` Max `1`។
2. សម្រាប់ NDWI/MNDWI៖ Color ramp «Blues» · Min `-1` Max `1`។
3. សម្រាប់ NDBI/BSI៖ Color ramp «OrRd»។
4. ថតរូបអេក្រង់សន្ទស្សន៍ទាំងប្រាំ។

## សកម្មភាពទី៣៖ យកគំរូ និងប្រៀបធៀប · ២៥ នាទី

1. ប្រើចំណុចគំរូពី[លំហាត់ទី៣](lab-03.md) (ឬបង្កើតថ្មី) សម្រាប់ថ្នាក់ប្រាំ។
2. **Sample raster values** ទាញតម្លៃទាំងប្រាំសន្ទស្សន៍សម្រាប់ចំណុចនីមួយៗ។
3. គណនាមធ្យមតាមថ្នាក់ ហើយបំពេញតារាង៖

    | ថ្នាក់ | NDVI | NDWI | MNDWI | NDBI | BSI |

    | ទឹក | | | | | |

    | តំបន់សាងសង់ | | | | | |

4. សម្រាប់ថ្នាក់នីមួយៗ គូសរង្វង់លើតម្លៃខ្ពស់បំផុត (ដែលបញ្ជាក់ថ្នាក់នោះបានច្បាស់បំផុត)។

## សកម្មភាពទី៤៖ វាយតម្លៃភាពបែងចែក · ១៥ នាទី

**សំណួរ**៖ ចម្លើយពីតារាងខាងលើ៖

1. សន្ទស្សន៍ណាបែងចែកទឹកបានច្បាស់បំផុតពីថ្នាក់ដទៃ?
2. សន្ទស្សន៍ណាបែងចែកតំបន់សាងសង់ពីដីទទេបានល្អបំផុត (ឬអត់អាចបែងចែកទាល់តែសោះ)?
3. តើ NDVI តែម្នាក់ឯង គ្រប់គ្រាន់ដើម្បីបែងចែកព្រៃឈើ និងស្រែទេ?

## សកម្មភាពទី៥៖ របាយការណ៍ខ្លី · ១៥ នាទី

សរសេរ ១ ទំព័រ៖ សន្ទស្សន៍ណាដែលអ្នកនឹងប្រើសម្រាប់ (ក) ផែនទីព្រៃឈើ (ខ) ផែនទីទឹកជំនន់ (គ) ការតាមដានការពង្រីកទីក្រុង ព្រមហេតុផលពីតារាងដែលអ្នកបានបំពេញ។
