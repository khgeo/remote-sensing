## ស្ថានភាព

អ្នកត្រូវមើលតំបន់មួយក្នុងខេត្តរបស់អ្នកពីលើ ដើម្បីដឹងថាមានស្រែ ព្រៃ ទឹក និងតំបន់សាងសង់នៅឯណា។ លំហាត់នេះនាំអ្នកពីការបង្កើតគណនី ដល់ការបង្កើតបន្សំពណ៌ដំបូង ហើយសំខាន់ជាងនេះ វាបង្រៀនអ្នក **អានរូបភាព** មិនមែនត្រឹមតែបើកវាទេ។

!!! abstract "អ្វីដែលអ្នកនឹងរៀនធ្វើ"
    ១. ស្វែងរក និងវាយតម្លៃរូបភាពមុនទាញយក (ថ្ងៃ ពពក tile កម្រិត)
    ២. យល់រចនាសម្ព័ន្ធឯកសារ `.SAFE` និងឈ្មោះរបស់វា
    ៣. បើកក្រុមរលកជាស្រទាប់ ហើយអានមេតាទិន្នន័យដែលសំខាន់
    ៤. បង្កើតបន្សំពណ៌ និងកែ stretch ដោយយល់ថាវាធ្វើអ្វី
    ៥. កាត់រូបភាពតាមតំបន់សិក្សា និងរក្សាទុកឲ្យត្រឹមត្រូវ

## សកម្មភាពទី២៖ បើកក្រុមរលក និងអានមេតាទិន្នន័យ · ២៥ នាទី

1. បន្ថែមក្រុមរលកនីមួយៗជាស្រទាប់រ៉ាស្ទ័រ (`B02.jp2` `B03.jp2` `B04.jp2` `B08.jp2` `B11.jp2` `B12.jp2`)។

## សកម្មភាពទី៣៖ បន្សំពណ៌ · ៣០ នាទី

1. **Raster → Miscellaneous → Build Virtual Raster**៖ ជ្រើស B4 B3 B2 · ធីក **Place each input file into a separate band** → `rgb_true.vrt`
2. Layer Properties → Symbology → **Multiband color**៖ Red = Band 1 (B4) · Green = Band 2 (B3) · Blue = Band 3 (B2)។
3. កំណត់ **Contrast enhancement → Stretch to MinMax** ជាមួយ **Cumulative count cut ២% – ៩៨%**។ សាកល្បងផងដែរ Min/Max = ០ ដល់ ៣ ០០០ ហើយប្រៀបធៀប។

    !!! note "ហេតុអ្វីត្រូវ stretch"
        តម្លៃភាគច្រើនប្រមូលផ្ដុំនៅផ្នែកទាបនៃជួរដែលអាចផ្ទុកបាន ដូច្នេះរូបភាពមើលទៅខ្មៅ។ ការ stretch ប្ដូរតែ **ការបង្ហាញ** មិនប្ដូរតម្លៃទិន្នន័យទេ។ នេះមានន័យថា ការ stretch ខុសគ្នាធ្វើឲ្យរូបភាពពីរមើលទៅខុសគ្នា ទោះទិន្នន័យដូចគ្នា ដែលជាហេតុផលដែលមិនត្រូវប្រៀបធៀបរូបភាពពីរដោយភ្នែក ដោយប្រើ stretch ខុសគ្នា។

4. ធ្វើម្ដងទៀតជាមួយ B8 B4 B3 → `rgb_false.vrt` និង B12 B8 B4 → `rgb_swir.vrt`។

    | វត្ថុ | ពណ៌ពិត | ពណ៌សន្មត | SWIR |

    | តំបន់សាងសង់ | | | |
    | ដីទទេ | | | |

6. ប្រៀបធៀបជាមួយការទាយរបស់អ្នកពីពិសោធន៍។ តើមានអ្វីខុសពីការរំពឹងទុក? ហេតុអ្វី?

## សកម្មភាពទី៤៖ កាត់តាមតំបន់សិក្សា · ២០ នាទី

1. បន្ថែម `Kh_Province_Boundary` ហើយ **Extract by expression** យកខេត្តរបស់អ្នក → `aoi`។
2. ពិនិត្យថា `aoi` និងរូបភាពមាន CRS ដូចគ្នា។ បើមិនដូច **Reproject** `aoi` ទៅ CRS នៃរូបភាព (មិនមែនផ្ទុយវិញទេ ព្រោះការ reproject រ៉ាស្ទ័របន្ថែមកំហុស)។
3. **Raster → Extraction → Clip Raster by Mask Layer** លើ `rgb_true.vrt` ជាមួយ `aoi`៖
    - ធីក **Match the extent of the clipped raster to the extent of the mask layer**
    - Nodata value៖ `0`
    → `aoi_true.tif`
4. ធ្វើដូចគ្នាសម្រាប់ពណ៌សន្មត និង SWIR។
5. ពិនិត្យទំហំឯកសារ និងចំនួនក្រឡាមុន និងក្រោយកាត់។
