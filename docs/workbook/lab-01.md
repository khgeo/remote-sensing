## ស្ថានភាព

អ្នកត្រូវមើលតំបន់មួយក្នុងខេត្តរបស់អ្នកពីលើ ដើម្បីដឹងថាមានស្រែ ព្រៃ ទឹក និងតំបន់សាងសង់នៅឯណា។ លំហាត់នេះនាំអ្នកពីការបង្កើតគណនី ដល់ការបង្កើតបន្សំពណ៌ដំបូងក្នុង QGIS។

## គោលបំណង

- បង្កើតគណនី Copernicus និងស្វែងរករូបភាព Sentinel-2 L2A។
- ទាញយករូបភាព ហើយពិនិត្យមេតាទិន្នន័យ៖ ថ្ងៃថត ពពក tile និង CRS។
- បើកក្រុមរលកក្នុង QGIS ហើយពិនិត្យទំហំក្រឡានីមួយៗ។
- បង្កើតបន្សំពណ៌ពិត និងពណ៌សន្មត ហើយប្រៀបធៀប។

## ឯកសារដែលប្រើ

- រូបភាព **Sentinel-2 L2A** មួយ ([ឧបសម្ព័ន្ធ ខ](../appendix/b-imagery-data.md))

## សកម្មភាពទី១៖ ស្វែងរក និងទាញយករូបភាព · ៣០ នាទី

1. បើក [Copernicus Browser](https://browser.dataspace.copernicus.eu/) ហើយបង្កើតគណនីឥតគិតថ្លៃ។
2. រុករកទៅខេត្តរបស់អ្នក រួចចុច **Search**៖
    - Data source៖ **Sentinel-2**
    - Product type៖ **L2A**
    - កាលបរិច្ឆេទ៖ ចន្លោះ ៣ ខែក្នុងរដូវប្រាំង (ធ្នូ ដល់ មីនា)
    - Max cloud coverage៖ **១០%**
3. ជ្រើសរូបភាពមួយ ហើយកត់ត្រាក្នុងតារាង៖

    | ធាតុ | តម្លៃ |
    |---|---|
    | ថ្ងៃ និងម៉ោងថត | |
    | លេខ tile (ឧ. T48PVU) | |
    | ភាគរយពពក | |
    | កម្រិតផលិតផល | L2A |
    | CRS | |

4. ទាញយក៖ ជ្រើស **Download** → ទម្រង់ `.SAFE` ឬទាញយកតែក្រុមរលក B2 B3 B4 B8 B11 B12 (JP2)។

!!! tip "ឯកសារធំ"
    រូបភាព `.SAFE` ពេញមួយមានទំហំប្រហែល ១ GB។ បើអ៊ីនធឺណិតយឺត ទាញយកតែក្រុមរលកដែលត្រូវការ ឬប្រើមុខងារ **Download image** នៃ Browser ដែលផ្ដល់រូបភាពតូចជាង (សម្រាប់មើលតែប៉ុណ្ណោះ មិនមែនសម្រាប់វិភាគទេ)។

## សកម្មភាពទី២៖ បើកក្រុមរលកក្នុង QGIS · ២០ នាទី

1. បន្ថែមក្រុមរលកនីមួយៗជាស្រទាប់រ៉ាស្ទ័រ (`B02.jp2` `B03.jp2` `B04.jp2` `B08.jp2` `B11.jp2` `B12.jp2`)។
2. សម្រាប់នីមួយៗ បើក **Layer Properties → Information** ហើយបំពេញ៖

    | ក្រុមរលក | រលក (ណាណូម៉ែត្រ) | ទំហំក្រឡា | ទំហំរូបភាព (ក្រឡា) |
    |---|---|---|---|
    | B2 ខៀវ | ~៤៩០ | | |
    | B3 បៃតង | ~៥៦០ | | |
    | B4 ក្រហម | ~៦៦៥ | | |
    | B8 NIR | ~៨៤២ | | |
    | B11 SWIR | ~១ ៦១០ | | |
    | B12 SWIR | ~២ ១៩០ | | |

3. ពិនិត្យ CRS របស់រូបភាព។ Sentinel-2 ប្រើ UTM · តើ zone ណាសម្រាប់កម្ពុជា?

## សកម្មភាពទី៣៖ បន្សំពណ៌ · ២៥ នាទី

1. **Raster → Miscellaneous → Build Virtual Raster**៖ ជ្រើស B4 B3 B2 · ធីក **Place each input file into a separate band** → `rgb_true.vrt`
2. Layer Properties → Symbology → **Multiband color**៖ Red = Band 1 (B4) · Green = Band 2 (B3) · Blue = Band 3 (B2)។
3. កំណត់ **Contrast enhancement → Stretch to MinMax** ជាមួយ **Cumulative count cut ២% – ៩៨%**។
4. ធ្វើម្ដងទៀតជាមួយ B8 B4 B3 → `rgb_false.vrt` (ពណ៌សន្មត)។
5. ប្រៀបធៀបទាំងពីរ ហើយឆ្លើយ៖ ទឹក ព្រៃ ស្រែ និងតំបន់សាងសង់ មានពណ៌អ្វីក្នុងនីមួយៗ?

!!! note "ហេតុអ្វីត្រូវ stretch"
    តម្លៃឆៅមានជួរតូចនៅផ្នែកងងឹត ដូច្នេះរូបភាពមើលទៅខ្មៅ។ ការ stretch ប្ដូរតែការបង្ហាញ មិនប្ដូរតម្លៃទិន្នន័យទេ ([មេរៀនទី៩](../lessons/lesson-09.md))។

## សកម្មភាពទី៤៖ កាត់តាមតំបន់សិក្សា · ២០ នាទី

1. បន្ថែម `Kh_Province_Boundary` ហើយ **Extract by expression** យកខេត្តរបស់អ្នក → `aoi`។
2. ពិនិត្យថា `aoi` និងរូបភាពមាន CRS ដូចគ្នា។ បើមិនដូច **Reproject** `aoi` ទៅ CRS នៃរូបភាព។
3. **Raster → Extraction → Clip Raster by Mask Layer** លើ `rgb_true.vrt` ជាមួយ `aoi` → `aoi_true.tif`។
4. ធ្វើដូចគ្នាសម្រាប់ពណ៌សន្មត។

## សកម្មភាពទី៥៖ ការសង្កេត · ១០ នាទី

សរសេរ ៥ ប្រយោគ៖ អ្វីដែលអ្នកសម្គាល់បានក្នុងរូបភាព · អ្វីដែលមើលមិនច្បាស់ · និងសំណួរមួយដែលរូបភាពនេះមិនអាចឆ្លើយ។

## លទ្ធផលត្រូវប្រគល់
