# លំហាត់ទី២៖ បរិយាកាស៖ ប្រៀបធៀប L1C និង L2A

!!! info "ព័ត៌មានលំហាត់"
    **មេរៀនពាក់ព័ន្ធ៖** [មេរៀនទី២៖ រលកអេឡិចត្រូម៉ាញេទិច និងបរិយាកាស](../lessons/lesson-02.md)
    **ការអនុវត្តដោយខ្លួនឯង** · QGIS 3.34 LTR · ប្រហែល ១១០ នាទី

## ស្ថានភាព

អ្នកមានរូបភាពតំបន់តែមួយ ក្នុងកម្រិតពីរ៖ **L1C** (ការចាំងផ្លាតកំពូលបរិយាកាស) និង **L2A** (ការចាំងផ្លាតផ្ទៃដី)។ គោលបំណងគឺមើលឲ្យឃើញដោយភ្នែក និងដោយលេខ ថាបរិយាកាសបន្ថែមអ្វីទៅរូបភាព ហើយហេតុអ្វីការវិភាគត្រូវប្រើ L2A។

## គោលបំណង

- ទាញយករូបភាពតែមួយក្នុងកម្រិត L1C និង L2A។
- ប្រៀបធៀបតម្លៃរវាងកម្រិតទាំងពីរ តាមក្រុមរលក។
- វាស់ឥទ្ធិពលនៃពន្លឺផ្លូវ និងអ័ព្ទលើក្រុមរលកខ្លី។
- ប្រើរបាំងពពក (SCL) ដើម្បីដកក្រឡាពពកចេញ។

## ឯកសារដែលប្រើ

- Sentinel-2 **L1C** និង **L2A** នៃ tile និងថ្ងៃដូចគ្នា ([ឧបសម្ព័ន្ធ ខ](../appendix/b-imagery-data.md))
- ស្រទាប់វ៉ិចទ័រតំបន់សិក្សារបស់អ្នក

## សកម្មភាពទី១៖ ទាញយករូបភាពពីរកម្រិត · ២៥ នាទី

1. ក្នុង Copernicus Browser រកថ្ងៃតែមួយលើតំបន់របស់អ្នក ដែលមានពពកតិច។
2. ទាញយក **L1C** និង **L2A** សម្រាប់ថ្ងៃ និង tile ដដែល។ (បើទំហំធំពេក ទាញយកតែ B2 B4 B8 B11 និងឯកសារ SCL របស់ L2A។)
3. កត់ត្រាទំហំឯកសារ និងកាលបរិច្ឆេទផលិត (processing baseline) របស់នីមួយៗ។

!!! note "តម្លៃខ្ទង់"
    ទិន្នន័យ Sentinel-2 ផ្ទុកជាចំនួនគត់។ ការចាំងផ្លាត = DN ÷ ១០ ០០០។ ចាប់ពី baseline 04.00 មានតម្លៃ offset (−១ ០០០) ដែលត្រូវដកចេញ។ ពិនិត្យមេតាទិន្នន័យ រួចប្រើរូបមន្តត្រឹមត្រូវក្នុង Raster Calculator៖ `(band - 1000) / 10000` ឬ `band / 10000`។

## សកម្មភាពទី២៖ ប្រៀបធៀបដោយភ្នែក · ២០ នាទី

1. បើកបន្សំពណ៌ពិត (B4-B3-B2) សម្រាប់ទាំង L1C និង L2A ដោយប្រើ **ការ stretch ដូចគ្នា** (Min 0 · Max 3000 ក្នុងតម្លៃ DN)។
2. ប្រៀបធៀបផ្ទាល់៖ តើមួយណាមានទឹកខ្មៅជាង? តើមួយណាមានកម្រិតពណ៌ខ្លាំងជាង?
3. ធ្វើដូចគ្នាជាមួយបន្សំ SWIR (B12-B8-B4)។ តើភាពខុសគ្នារវាង L1C និង L2A ធំជាង ឬតូចជាងក្នុងបន្សំនេះ?

## សកម្មភាពទី៣៖ ប្រៀបធៀបដោយលេខ · ៣០ នាទី

1. បង្កើតចំណុចគំរូ ១០ (Random points ក្នុងតំបន់សិក្សា) ដែលគ្របដណ្ដប់ទឹក ព្រៃ ស្រែ និងតំបន់សាងសង់។
2. **Processing → Raster analysis → Sample raster values** ដើម្បីទាញតម្លៃពី L1C និង L2A។
3. បំពេញតារាង (បម្លែងទៅការចាំងផ្លាតជាភាគរយ)៖

    | ចំណុច | គម្របដី | B2 L1C | B2 L2A | ភាពខុស | B11 L1C | B11 L2A | ភាពខុស |
    |---|---|---:|---:|---:|---:|---:|---:|
    | ១ | | | | | | | |

4. គណនាមធ្យមនៃភាពខុសគ្នាសម្រាប់ B2 និង B11។

**សំណួរ៖** ក្រុមរលកណាដែលមានភាពខុសគ្នាធំជាង? តើវាស្របនឹងទ្រឹស្ដីការខ្ចាត់ខ្ចាយឬទេ?

## សកម្មភាពទី៤៖ របាំងពពក · ២០ នាទី

1. បន្ថែមស្រទាប់ **SCL** (Scene Classification Layer · ២០ ម) របស់ L2A។
2. តម្លៃសំខាន់៖ ៣ = ស្រមោលពពក · ៨ = ពពកប្រូបាប៊ីលីតេមធ្យម · ៩ = ពពកប្រូបាប៊ីលីតេខ្ពស់ · ១០ = cirrus · ១១ = ព្រិល/ទឹកកក។
3. **Raster Calculator** បង្កើតរបាំង៖

    ```text
    ("SCL@1" != 3) AND ("SCL@1" != 8) AND ("SCL@1" != 9) AND ("SCL@1" != 10)
    ```

4. គុណរបាំងនឹងក្រុមរលកនីមួយៗ ឬប្រើវាជា NoData mask។ គណនាភាគរយក្រឡាដែលនៅសល់។

## សកម្មភាពទី៥៖ ការសន្និដ្ឋាន · ១៥ នាទី

សរសេរ ៥ ប្រយោគ៖ អ្វីដែលបរិយាកាសបន្ថែម · ក្រុមរលកណារងផលច្រើនបំផុត · និងហេតុអ្វីអ្នកនឹងប្រើ L2A សម្រាប់ការវិភាគទាំងអស់។

## លទ្ធផលត្រូវប្រគល់

- តារាងប្រៀបធៀបតម្លៃ និងមធ្យមនៃភាពខុសគ្នា។
- រូបភាពប្រៀបធៀបពណ៌ពិត L1C និង L2A។
- របាំងពពក និងភាគរយក្រឡាប្រើការបាន។
