## ស្ថានភាព

អ្នកត្រូវណែនាំថាគម្រោងមួយគួរប្រើ Sentinel-2 ឬ Landsat។ ជំនួសឲ្យការជឿតាមឯកសារ អ្នកនឹងទាញយករូបភាពទាំងពីរលើតំបន់ដដែល ហើយវាស់ភាពខុសគ្នាដោយខ្លួនឯង។

## គោលបំណង

- ទាញយក Landsat 8/9 Collection 2 Level-2 និងប្រៀបធៀបជាមួយ Sentinel-2 L2A។
- ប្រៀបធៀបក្រឡា ចំនួនក្រឡា និងទំហំឯកសារ។
- ពិនិត្យលម្អិតលំហដោយផ្ទាល់ លើវត្ថុតូចៗ។
- វិភាគភាពមានរូបភាពតាមពេលវេលា (ពពក និងវដ្ដមកម្ដងទៀត)។

## សកម្មភាពទី១៖ ទាញយក Landsat · ២០ នាទី

1. បង្កើតគណនី USGS ហើយស្វែងរក Landsat 8/9 OLI/TIRS **Collection 2 Level-2** លើតំបន់របស់អ្នក។
2. ជ្រើសរូបភាពដែលថ្ងៃថតជិតនឹង Sentinel-2 របស់អ្នក (ក្នុងចន្លោះ ១០ ថ្ងៃ បើអាច)។
3. ទាញយកក្រុមរលក SR_B2 ដល់ SR_B7 និងឯកសារមេតាទិន្នន័យ (MTL)។

!!! note "តម្លៃខ្ទង់ Landsat Collection 2 L2"
    ការចាំងផ្លាត = `DN × 0.0000275 − 0.2`។ សម្រាប់ក្រុមរលកកំដៅ សីតុណ្ហភាព (K) = `DN × 0.00341802 + 149.0`។

## សកម្មភាពទី២៖ ប្រៀបធៀបលក្ខណៈ · ២០ នាទី

បំពេញតារាងដោយអានពី Layer Properties និងមេតាទិន្នន័យ៖

| លក្ខណៈ | Sentinel-2 L2A | Landsat 8/9 L2 |
|---|---|---|
| ថ្ងៃ និងម៉ោងថត (UTC) | | |
| ក្រឡា (ក្រហម NIR SWIR) | | |
| ចំនួនក្រឡាក្នុងតំបន់សិក្សា | | |
| ទំហំឯកសារ | | |
| CRS | | |
| ក្រុមរលកកំដៅ | គ្មាន | មាន (១០០ ម) |

សម្រាប់ចំនួនក្រឡា៖ កាត់ទាំងពីរតាមតំបន់សិក្សា រួចអាន Layer Properties → Information។

## សកម្មភាពទី៣៖ ប្រៀបធៀបលម្អិតលំហ · ២៥ នាទី

1. ពង្រីកទៅតំបន់ដែលមានវត្ថុលីនេអ៊ែរតូច៖ ផ្លូវជាតិ ប្រឡាយ ឬព្រំស្រែ។
2. ដាក់ទាំងពីរក្នុងបន្សំពណ៌សន្មតដូចគ្នា ហើយប្រើ **Map Swipe Tool** ដើម្បីប្រៀបធៀប។
3. រកវត្ថុពីរ៖ មួយដែលមើលឃើញក្នុងទាំងពីរ និងមួយដែលមើលឃើញតែក្នុង Sentinel-2។ ថតរូបអេក្រង់។
4. វាស់ទទឹងវត្ថុទាំងនោះដោយ Measure Line ហើយប្រៀបធៀបជាមួយក្បួន «២ ទៅ ៣ ក្រឡា»។

## សកម្មភាពទី៤៖ ភាពមានរូបភាព · ២០ នាទី

1. ក្នុង Copernicus Browser រាប់ចំនួនរូបភាព Sentinel-2 លើតំបន់របស់អ្នក ក្នុងឆ្នាំកន្លងមក ដែលមានពពក < ២០%។
2. ធ្វើដូចគ្នាសម្រាប់ Landsat ក្នុង EarthExplorer។
3. គូសតារាងតាមខែ៖ ខែណាមានរូបភាពប្រើការបានច្រើន? ខែណាគ្មានសោះ?
4. ភ្ជាប់លទ្ធផលនឹងរដូវវស្សា និងវដ្ដមកម្ដងទៀតដែលអ្នកបានគណនាក្នុងមេរៀនទី៤។

## សកម្មភាពទី៥៖ អនុសាសន៍ · ១៥ នាទី

សរសេរអនុសាសន៍មួយកថាខណ្ឌ៖ គម្រោងគួរប្រើផ្កាយរណបណា ក្នុងស្ថានភាពណា ហើយហេតុអ្វី។ បញ្ចូលករណីដែល Landsat ល្អជាង (ប្រវត្តិយូរ ក្រុមរលកកំដៅ)។
