# លំហាត់ទី៩៖ បង្កើតកំណែពណ៌ច្រើនបែបសម្រាប់របាយការណ៍

!!! info "ព័ត៌មានលំហាត់"
    **មេរៀនពាក់ព័ន្ធ៖** [មេរៀនទី៩៖ ការបង្ហាញរូបភាព និងបន្សំក្រុមរលក](../lessons/lesson-09.md)
    **ការអនុវត្តដោយខ្លួនឯង** · QGIS 3.34 LTR · ប្រហែល ១០០ នាទី

## ស្ថានភាព

របាយការណ៍របស់អ្នកត្រូវការរូបភាពបួនបែប៖ មួយសម្រាប់សាធារណជនទូទៅ និងបីសម្រាប់ការវិភាគជំនាញ។ លំហាត់នេះឲ្យអ្នកបង្កើត និងកំណត់រចនាប័ទ្មរូបភាពទាំងអស់នោះ ព្រមទាំងរក្សាទុកជា `.qml` សម្រាប់ប្រើឡើងវិញ។

## គោលបំណង

- កំណត់ Contrast enhancement ត្រឹមត្រូវសម្រាប់បន្សំនីមួយៗ។
- បង្កើត និងប្រៀបធៀបបន្សំក្រុមរលកយ៉ាងតិចប្រាំ។
- រក្សាទុក និងអនុវត្តរចនាប័ទ្មឡើងវិញ (.qml)។
- ធ្វើផ្ទាំងប្រៀបធៀប (Print Layout) បង្ហាញបន្សំច្រើន។

## ឯកសារដែលប្រើ

- រូបភាព Sentinel-2 L2A ពីលំហាត់មុន

## ពិសោធន៍មុនចាប់ផ្ដើម · ១៥ នាទី

## សកម្មភាពទី១៖ បង្កើតបន្សំប្រាំ · ៤០ នាទី

សម្រាប់បន្សំនីមួយៗ បន្ថែមរូបភាពជាស្រទាប់ថ្មី កំណត់ Symbology → Multiband color និង Contrast enhancement (Cumulative ២–៩៨%)៖

| # | បន្សំ (R-G-B) | ឈ្មោះស្រទាប់ |
|---|---|---|
| ១ | B4-B3-B2 | true_colour |
| ២ | B8-B4-B3 | false_nir |
| ៣ | B11-B8-B2 | agriculture |
| ៤ | B12-B11-B4 | urban |
| ៥ | B4-B3-B1 | bathymetric |

សម្រាប់នីមួយៗ ចុចស្ដាំលើស្រទាប់ → **Export → Save as QGIS Layer Style File (.qml)**។

## សកម្មភាពទី២៖ ប្រៀបធៀប stretch · ២០ នាទី

1. លើបន្សំ true_colour សាកល្បង stretch បួនវិធី (គ្មាន · Min-Max · Cumulative ២–៩៨% · Standard Deviation)។
2. ថតរូបអេក្រង់នីមួយៗ។ កត់ត្រាដែន Min/Max ដែល QGIS គណនា។
3. ជ្រើសវិធីមួយសម្រាប់ប្រើក្នុងរបាយការណ៍ចុងក្រោយ ព្រមហេតុផល។

## សកម្មភាពទី៣៖ ប្រៀបធៀបស៊ីគ្នារវាងស្រទាប់ · ១៥ នាទី

1. ជ្រើសពីរស្រទាប់ណាមួយ (ឧ. true_colour ថតឆ្នាំនេះ និងឆ្នាំមុន បើអាចរក)។
2. កំណត់ Min/Max ដូចគ្នាដោយដៃលើទាំងពីរ (មិនប្រើ stretch ស្វ័យប្រវត្តិ)។
3. ពន្យល់ថាហេតុអ្វីជំហាននេះចាំបាច់សម្រាប់ការប្រៀបធៀបត្រឹមត្រូវ។

## សកម្មភាពទី៤៖ ផ្ទាំងប្រៀបធៀប · ២០ នាទី

<div class="sim" data-sim="rs-pansharpen"></div>

1. បង្កើត Print Layout ជាមួយក្រឡាចត្រង្គ ២ × ២ ឬ ២ × ៣ បង្ហាញបន្សំផ្សេងៗលើតំបន់ដូចគ្នា។
2. បន្ថែមចំណងជើងរងសម្រាប់ផែនទីនីមួយៗ (ឈ្មោះបន្សំ)។
3. បន្ថែមកំណត់សម្គាល់ពន្យល់ន័យបន្សំ NIR (ក្រហមភ្លឺ = រុក្ខជាតិ)។

## សកម្មភាពទី៥៖ ការសន្និដ្ឋាន · ១០ នាទី

សរសេរ ៤ ប្រយោគ៖ បន្សំណាបង្ហាញព័ត៌មានច្រើនបំផុតសម្រាប់តំបន់របស់អ្នក ជាក់លាក់ និងហេតុអ្វី។

## លទ្ធផលត្រូវប្រគល់

- ឯកសារ `.qml` ប្រាំសម្រាប់បន្សំនីមួយៗ។
- រូបថតអេក្រង់ប្រៀបធៀបវិធី stretch បួន។
- ផ្ទាំងប្រៀបធៀបបន្សំ (Print Layout PDF)។
