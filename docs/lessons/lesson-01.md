# មេរៀនទី១៖ ការយកព័ត៌មានពីចម្ងាយជាអ្វី

!!! info "ព័ត៌មានមេរៀន"
    **រយៈពេលបង្រៀនដែលស្នើ៖ ៣ ម៉ោង** · មេរៀនទី ១ ក្នុងចំណោម ១៥

**ការយកព័ត៌មានពីចម្ងាយ (Remote Sensing)** គឺជាការទទួលព័ត៌មានអំពីវត្ថុ ឬផ្ទៃដី **ដោយមិនប៉ះវា**។ ផ្កាយរណបវាស់ថាមពលដែលឆ្លុះបញ្ចាំង ឬបញ្ចេញពីផ្ទៃដី រួចបម្លែងវាទៅជារូបភាពដែលយើងអាចវាស់ និងវិភាគបាន។

មេរៀនដំបូងនេះពន្យល់ថាតើរូបភាពផ្កាយរណបកើតឡើងយ៉ាងណា វេទិកា និងឧបករណ៍ចាប់សញ្ញាមានប្រភេទណាខ្លះ អ្វីដែលការយកព័ត៌មានពីចម្ងាយអាចធ្វើបាន និងអ្វីដែលវាមិនអាចធ្វើបាន។

---

## ១.១. គោលបំណងសិក្សា

បន្ទាប់ពីបញ្ចប់មេរៀន និស្សិតអាច៖

1. ពន្យល់និយមន័យ និងខ្សែសង្វាក់ថាមពលនៃការយកព័ត៌មានពីចម្ងាយ។
2. បែងចែកឧបករណ៍ចាប់សញ្ញាអកម្ម (passive) និងសកម្ម (active)។
3. ប្រៀបធៀបវេទិកា៖ ដ្រូន យន្តហោះ ផ្កាយរណបគន្លងប៉ូល និងផ្កាយរណបឋិតិវន្ត។
4. ពន្យល់ថាហេតុអ្វីវត្ថុនីមួយៗលេចឡើងខុសគ្នាក្នុងបន្សំក្រុមរលកខុសគ្នា។
5. កំណត់សំណួរណាដែលរូបភាពផ្កាយរណបអាចឆ្លើយបាន និងណាដែលមិនអាច។

### ចំណេះដឹងមុនត្រូវមាន

- ខ្លឹមសារ[សៀវភៅទី១](https://khgeo.github.io/cartography/)៖ CRS មាត្រដ្ឋាន និងការរចនាផែនទី។
- ខ្លឹមសារ[សៀវភៅទី២](https://khgeo.github.io/gis-fundamentals/)៖ គំរូទិន្នន័យរ៉ាស្ទ័រ ក្រឡា និង NoData។

## ១.២. ស្ថានភាពបើកមេរៀន៖ ភូមិណាខ្លះលិចទឹកកាលពីខែមុន?

ខេត្តមួយត្រូវរាយការណ៍តំបន់លិចទឹកនៃខែមុន។ ក្រុមការងារមិនអាចចុះទៅគ្រប់ឃុំបានទេ ហើយទឹកបានស្រកខ្លះរួចហើយ។ សំណួរគឺ៖ តើមានវិធីមើលអតីតកាលដែរឬទេ?

ផ្កាយរណប **Sentinel-2** ឆ្លងកាត់លើកម្ពុជា **រៀងរាល់ប្រហែល ៥ ថ្ងៃ** ហើយរូបភាពទាំងអស់ជាទិន្នន័យបើកចំហ។ ប្រសិនបើមានថ្ងៃដែលគ្មានពពកក្នុងសប្ដាហ៍នោះ យើងអាចមើលឃើញវិសាលភាពទឹកបាន។

ប៉ុន្តែ៖ ពពកអាចបាំង · ទឹកក្រោមព្រៃមើលមិនឃើញ · ហើយក្រឡា ១០ ម មិនបង្ហាញផ្ទះមួយខ្នងៗទេ។

សំណួរដែលមេរៀននេះឆ្លើយ៖

- រូបភាពផ្កាយរណបកើតឡើងយ៉ាងណា?
- ហេតុអ្វីទឹកមើលទៅខ្មៅ ឯព្រៃមើលទៅក្រហមក្នុងរូបភាពពណ៌សន្មត?
- តើសំណួរណាដែលរូបភាពអាចឆ្លើយបាន?

---

## ១.៣. ទ្រឹស្ដីស្នូល

### ១.៣.១. និយមន័យ និងខ្សែសង្វាក់ថាមពល

ការយកព័ត៌មានពីចម្ងាយវាស់ **ថាមពលអេឡិចត្រូម៉ាញេទិច** ដែលមកពីវត្ថុ។ ខ្សែសង្វាក់មាន ៧ ជំហាន៖

<figure markdown>
--8<-- "assets/svg/r01-chain.svg"
<figcaption>រូបទី១.១៖ ខ្សែសង្វាក់នៃការយកព័ត៌មានពីចម្ងាយ៖ ថាមពលពីព្រះអាទិត្យឆ្លងកាត់បរិយាកាស ឆ្លុះបញ្ចាំងពីផ្ទៃដី ត្រូវបានវាស់ដោយឧបករណ៍ រួចក្លាយជាទិន្នន័យ ការវិភាគ និងព័ត៌មាន។</figcaption>
</figure>

ចំណុចសំខាន់៖ ឧបករណ៍ចាប់សញ្ញាមិនវាស់ «ព្រៃឈើ» ឬ «ទឹក» ទេ។ វាវាស់ **ថាមពលក្នុងក្រុមរលកនីមួយៗ**។ ការបម្លែងថាមពលនោះទៅជាព័ត៌មានអំពីក្រប់ដី គឺជាការងាររបស់អ្នកវិភាគ ដែលជាខ្លឹមសារនៃសៀវភៅទាំងមូលនេះ។

### ១.៣.២. ឧបករណ៍អកម្ម និងសកម្ម

| | អកម្ម (Passive) | សកម្ម (Active) |
|---|---|---|
| ប្រភពថាមពល | ព្រះអាទិត្យ ឬកំដៅពីវត្ថុ | ឧបករណ៍បញ្ចេញថាមពលដោយខ្លួនឯង |
| ឧទាហរណ៍ | Sentinel-2 · Landsat · MODIS | រ៉ាដា SAR (Sentinel-1) · LiDAR |
| ពេលយប់ | មិនបាន (លើករលែងកំដៅ) | បាន |
| ពពក | បាំង | រលករ៉ាដាឆ្លងកាត់ពពកបាន |
| ឯកតាដែលវាស់ | ការឆ្លុះបញ្ចាំង (reflectance) | ការបែកខ្ចាត់ត្រឡប់ (backscatter) |

នៅកម្ពុជា ដែលរដូវវស្សាមានពពកច្រើន រ៉ាដា **Sentinel-1** ជាឧបករណ៍សំខាន់សម្រាប់ធ្វើផែនទីទឹកជំនន់ និងស្រែវស្សា។ រ៉ាដានឹងសិក្សាក្នុង[មេរៀនទី១៥](lesson-15.md)។

### ១.៣.៣. វេទិកា

<figure markdown>
--8<-- "assets/svg/r01-platforms.svg"
<figcaption>រូបទី១.២៖ វេទិកា និងលក្ខណៈធម្មតារបស់វា។ កម្ពស់កាន់តែខ្ពស់ ទទឹងថតកាន់តែធំ និងការមកម្ដងទៀតកាន់តែញឹក ប៉ុន្តែក្រឡាកាន់តែធំ។</figcaption>
</figure>

**គន្លងប៉ូល (Polar orbit)**៖ ផ្កាយរណបវិលឆ្លងកាត់ប៉ូល ហើយផែនដីវិលក្រោមវា ដូច្នេះវាថតឆ្នូតថ្មីរាល់ជុំ។ **គន្លងព្រះអាទិត្យសមកាល (Sun-synchronous)** មានន័យថាវាឆ្លងកាត់អេក្វាទ័រនៅម៉ោងថ្ងៃដដែលជានិច្ច (Sentinel-2 ប្រហែលម៉ោង ១០:៣០ ព្រឹកតាមម៉ោងមូលដ្ឋាន) ដែលធ្វើឲ្យស្រមោល និងពន្លឺប្រហាក់ប្រហែលគ្នារវាងថ្ងៃផ្សេងៗ។

**គន្លងឋិតិវន្ត (Geostationary)**៖ នៅកម្ពស់ ៣៥ ៧៨៦ គម ផ្កាយរណបវិលក្នុងល្បឿនដូចផែនដី ដូច្នេះវាមើលតំបន់ដដែលជានិច្ច។ ល្អសម្រាប់អាកាសធាតុ (រៀងរាល់ ១០ នាទី) ប៉ុន្តែក្រឡាធំពេកសម្រាប់ការធ្វើផែនទីក្រប់ដី។

### ១.៣.៤. អ្វីដែលឧបករណ៍ឃើញ

វត្ថុនីមួយៗឆ្លុះបញ្ចាំងរលកខុសគ្នា។ ឧទាហរណ៍ រុក្ខជាតិដែលមានសុខភាពល្អ ស្រូបពន្លឺក្រហម (សម្រាប់រស្មីសំយោគ) ប៉ុន្តែ **ឆ្លុះអ៊ីនហ្វ្រាក្រហមជិត (NIR) ខ្លាំង**។ ទឹកស្រូបស្ទើរគ្រប់រលក ជាពិសេស NIR ដូច្នេះវាមើលទៅខ្មៅ។

!!! example "ពិសោធន៍៖ តើផ្កាយរណបឃើញអ្វី?"
    ប្ដូររវាងបន្សំក្រុមរលកបី ហើយសង្កេតថាទឹក ព្រៃ ស្រែ និងតំបន់សាងសង់ប្ដូរពណ៌យ៉ាងណា។ បើកស្រទាប់ក្រប់ដី ដើម្បីផ្ទៀងផ្ទាត់ការទាយរបស់អ្នក។

<div class="sim" data-sim="rs-view"></div>

**បន្សំក្រុមរលក (Band combination)** កំណត់ថាភ្នែកយើងឃើញអ្វី៖

| បន្សំ | Sentinel-2 | ប្រើសម្រាប់ |
|---|---|---|
| ពណ៌ពិត | B4-B3-B2 | មើលបែបធម្មជាតិ · បង្ហាញដល់សាធារណជន |
| ពណ៌សន្មត (NIR) | B8-B4-B3 | រុក្ខជាតិ (ក្រហម = រុក្ខជាតិមានសុខភាព) |
| SWIR | B12-B8-B4 | សំណើម ដី ភ្លើងឆេះ តំបន់សាងសង់ |
| Agriculture | B11-B8-B2 | បែងចែកប្រភេទដំណាំ |

ហត្ថលេខាស្ពិចត្រាល់ (spectral signature) នឹងសិក្សាលម្អិតក្នុង[មេរៀនទី៣](lesson-03.md)។

### ១.៣.៥. ក្រឡា និងអ្វីដែលអាចសម្គាល់

រូបភាពផ្កាយរណបជា **រ៉ាស្ទ័រ** ([មេរៀនទី៣ សៀវភៅទី២](https://khgeo.github.io/gis-fundamentals/lessons/lesson-03/))។ ក្រឡានីមួយៗមានតម្លៃមួយក្នុងមួយក្រុមរលក ហើយតម្លៃនោះជា **មធ្យមនៃអ្វីៗទាំងអស់ក្នុងក្រឡា** ដែលហៅថា **ក្រឡាចម្រុះ (mixed pixel)**។

!!! example "ពិសោធន៍៖ ទំហំក្រឡា"
    ប្ដូរទំហំក្រឡាពី ១០ ម ទៅ ២៥០ ម ហើយសង្កេតថាវត្ថុណាបាត់មុនគេ។ បិទ «ក្រឡាចម្រុះ» ដើម្បីមើលភាពខុសគ្នារវាងការយកមធ្យម និងការយកក្រឡាកណ្ដាល។

ក្បួនជាក់ស្ដែង៖ ដើម្បីសម្គាល់វត្ថុមួយ **ត្រូវការយ៉ាងតិច ២ ទៅ ៣ ក្រឡា** លើវត្ថុនោះ។ ដូច្នេះក្រឡា ១០ ម មិនអាចសម្គាល់ផ្ទះមួយខ្នងបានទេ ប៉ុន្តែអាចសម្គាល់ស្រែមួយក្បាល និងផ្លូវជាតិបាន។

### ១.៣.៦. អ្វីដែលអាច និងមិនអាច

| រូបភាពផ្កាយរណបអាចឆ្លើយ | មិនអាចឆ្លើយដោយខ្លួនឯង |
|---|---|
| តំបន់ព្រៃឈើប្ដូរប៉ុន្មានហិកតា រវាងឆ្នាំពីរ | ហេតុអ្វីព្រៃត្រូវបានកាប់ និងដោយអ្នកណា |
| វិសាលភាពទឹកជំនន់នៅថ្ងៃដែលគ្មានពពក | ជម្រៅទឹក ឬការខូចខាតក្នុងផ្ទះ |
| ស្រែត្រូវបានស្ទូងនៅពេលណា (តាមស៊េរីពេលវេលា) | ម្ចាស់ដី ឬទិន្នផលពិតប្រាកដ |
| តំបន់សាងសង់ពង្រីកទៅណា | ចំនួនប្រជាជនក្នុងអគារ |
| សីតុណ្ហភាពផ្ទៃដី | សីតុណ្ហភាពខ្យល់ក្នុងផ្ទះ |

ការយកព័ត៌មានពីចម្ងាយ **បំពេញ** ការស្ទង់នៅទីវាល មិនជំនួសវាទេ។ ការវិភាគល្អតែងផ្សំទាំងពីរ ហើយចំណុចផ្ទៀងផ្ទាត់នៅទីវាល ជាមូលដ្ឋាននៃការវាយតម្លៃភាពត្រឹមត្រូវ ([មេរៀនទី១៣](lesson-13.md))។

## ១.៤. ឧទាហរណ៍ដែលបានដោះស្រាយ៖ ជ្រើសរូបភាពសម្រាប់សំណួរបី

សំណួរបីពិតប្រាកដនៅកម្ពុជា ត្រូវការរូបភាពខុសគ្នា។

### ជំហានទី១៖ ផ្ទៃស្រែក្នុងខេត្តកំពង់ឆ្នាំង

ស្រែមួយក្បាលធំជាង ១ ហ.ត (១០០ × ១០០ ម) → ក្រឡា ១០ ម គ្រប់គ្រាន់។ ត្រូវការក្រុមរលក NIR និង SWIR → **Sentinel-2 L2A** ក្នុងរដូវប្រាំង (ពពកតិច)។

### ជំហានទី២៖ វិសាលភាពទឹកជំនន់ក្នុងខែកញ្ញា

រដូវវស្សា ពពកច្រើន → រូបភាពអុបទិកអាចមិនមាន។ ដំណោះស្រាយ៖ **រ៉ាដា Sentinel-1** ដែលឆ្លងកាត់ពពក ឬរូបភាព Sentinel-2 នៃថ្ងៃដែលពពកតិច (ពិនិត្យតម្លៃ cloud cover)។

### ជំហានទី៣៖ ការពង្រីកទីក្រុងភ្នំពេញពីឆ្នាំ ២០០០

ត្រូវការទិន្នន័យចាស់ → **Landsat 5/7/8** ដែលមានតាំងពីទសវត្សរ៍ ១៩៨០។ ក្រឡា ៣០ ម គ្រប់គ្រាន់សម្រាប់តំបន់សាងសង់ ប៉ុន្តែមិនសម្រាប់អគារនីមួយៗទេ។

### ជំហានទី៤៖ ការសម្រេចចិត្តរួម

| សំណួរ | ឧបករណ៍ | ក្រឡា | មូលហេតុ |
|---|---|---|---|
| ផ្ទៃស្រែ | Sentinel-2 | ១០ ម | លម្អិតល្អ · មាន NIR និង SWIR |
| ទឹកជំនន់រដូវវស្សា | Sentinel-1 (រ៉ាដា) | ១០ ម | ឆ្លងកាត់ពពក |
| ការពង្រីកទីក្រុង ២០០០–២០២៥ | Landsat | ៣០ ម | មានទិន្នន័យតាំងពីយូរ |

### សេចក្ដីសន្និដ្ឋានដែលសមស្រប

> «ការជ្រើសរូបភាពចាប់ផ្ដើមពីសំណួរ៖ ទំហំវត្ថុកំណត់ក្រឡា · ពេលវេលា និងពពកកំណត់ឧបករណ៍ · ហើយរយៈពេលប្រវត្តិសាស្ត្រកំណត់ថាអាចប្រើផ្កាយរណបណា។»

!!! warning "អ្វីដែលយើងមិនអាចសន្និដ្ឋាន"
    យើងមិនអាចជ្រើសរូបភាពដោយផ្អែកលើក្រឡាតែម្នាក់ឯងទេ។ រូបភាពក្រឡាតូចដែលមានពពក ឬដែលថតខុសរដូវ មិនមានប្រយោជន៍ជាងរូបភាពក្រឡាធំដែលថតត្រូវពេលនោះទេ។

## ១.៥. សកម្មភាពអនុវត្ត

!!! tip "លំហាត់នេះស្ថិតក្នុងសៀវភៅអនុវត្ត"
    ការអនុវត្តលើ QGIS សម្រាប់មេរៀននេះស្ថិតក្នុង [**លំហាត់ទី១**](../workbook/lab-01.md)។

    និស្សិតធ្វើលំហាត់នេះ **ដោយខ្លួនឯង** នៅក្រៅម៉ោងរៀន។

## ១.៦. ការយល់ច្រឡំដែលត្រូវប្រុងប្រយ័ត្ន

**១. «រូបភាពផ្កាយរណបជារូបថតធម្មតា»**
វាជាការវាស់ថាមពលក្នុងក្រុមរលកជាច្រើន រួមទាំងរលកដែលភ្នែកមនុស្សមើលមិនឃើញ។

**២. «ក្រឡា ១០ ម មានន័យថាឃើញវត្ថុ ១០ ម»**
ដើម្បីសម្គាល់វត្ថុ ត្រូវការ ២ ទៅ ៣ ក្រឡាលើវត្ថុនោះ។

**៣. «ផ្កាយរណបថតរូបភាពរាល់ថ្ងៃគ្រប់កន្លែង»**
គន្លង និងទទឹងថតកំណត់រយៈពេលមកម្ដងទៀត។ Sentinel-2 ប្រហែល ៥ ថ្ងៃ · Landsat ១៦ ថ្ងៃក្នុងមួយផ្កាយរណប។

**៤. «ពណ៌ក្នុងរូបភាពជាពណ៌ពិតជានិច្ច»**
ពណ៌អាស្រ័យលើបន្សំក្រុមរលកដែលអ្នកជ្រើស។ ក្រហមក្នុងរូបភាពពណ៌សន្មត មានន័យថារុក្ខជាតិ។

**៥. «ការយកព័ត៌មានពីចម្ងាយជំនួសការចុះទីវាល»**
វាកាត់បន្ថយការចុះទីវាល ប៉ុន្តែការវាយតម្លៃភាពត្រឹមត្រូវនៅតែត្រូវការចំណុចយោងពិត។

## ១.៧. សេចក្ដីសង្ខេបមេរៀន

ការយកព័ត៌មានពីចម្ងាយវាស់ថាមពលអេឡិចត្រូម៉ាញេទិចដែលឆ្លុះបញ្ចាំង ឬបញ្ចេញពីផ្ទៃដី។ ឧបករណ៍អកម្មពឹងលើព្រះអាទិត្យ ឯឧបករណ៍សកម្មបញ្ចេញថាមពលដោយខ្លួនឯង ហើយឆ្លងកាត់ពពកបាន។

វេទិកាខុសគ្នាផ្ដល់តុល្យភាពខុសគ្នារវាងលម្អិត ទទឹងថត និងរយៈពេលមកម្ដងទៀត។ វត្ថុលេចឡើងខុសគ្នាតាមបន្សំក្រុមរលក ហើយក្រឡាចម្រុះកំណត់អ្វីដែលអាចសម្គាល់បាន។

!!! abstract "គំនិតស្នូលនៃមេរៀន"
    ផ្កាយរណបមិនឃើញ «ព្រៃ» ឬ «ទឹក» ទេ។ វាវាស់ថាមពលក្នុងក្រុមរលក ហើយការបកស្រាយ គឺជាការងាររបស់អ្នក។

## ១.៩. សំណួររំលឹក និងវាយតម្លៃ

### ក. សំណួរយល់ដឹង

1. កំណត់និយមន័យការយកព័ត៌មានពីចម្ងាយ និងរាយជំហានខ្សែសង្វាក់ថាមពល។
2. បែងចែកឧបករណ៍អកម្ម និងសកម្ម ព្រមទាំងឧទាហរណ៍មួយសម្រាប់នីមួយៗ។
3. ហេតុអ្វីទឹកមើលទៅខ្មៅក្នុងរូបភាព NIR?
4. គន្លងព្រះអាទិត្យសមកាលមានប្រយោជន៍អ្វី?
5. ក្រឡាចម្រុះជាអ្វី ហើយវាប៉ះពាល់ការវិភាគយ៉ាងណា?

### ខ. សំណួរអនុវត្តគោលគំនិត

6. ស្នើឧបករណ៍ និងក្រឡាសម្រាប់៖ (ក) ការតាមដានការកាប់ព្រៃក្នុងខេត្តកោះកុង (ខ) ការរាប់អគារក្នុងក្រុងសៀមរាប (គ) ការតាមដានទឹកជំនន់រដូវវស្សា។
7. ភូមិមួយមានទទឹងប្រហែល ៣០០ ម។ តើក្រឡា ២៥០ ម គ្រប់គ្រាន់ដើម្បីសម្គាល់វាទេ? ពន្យល់។

9. ចូររាយសំណួរបីអំពីតំបន់របស់អ្នក ដែលរូបភាពផ្កាយរណបអាចឆ្លើយបាន និងពីរដែលមិនអាច។
