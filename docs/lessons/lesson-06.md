# មេរៀនទី៦៖ ប្រភពរូបភាព និងការទាញយក

!!! info "ព័ត៌មានមេរៀន"
    **រយៈពេលបង្រៀនដែលស្នើ៖ ៣ ម៉ោង** · មេរៀនទី ៦ ក្នុងចំណោម ១៥

ក្នុងឆ្នាំ ១៩៩០ ការទទួលបានរូបភាពផ្កាយរណបមួយសន្លឹក ត្រូវការទាំងថវិកា ទាំងទំនាក់ទំនងជាមួយភ្នាក់ងារអវកាស។ សព្វថ្ងៃ អ្នកអាចទាញយករូបភាព Sentinel-2 ដោយឥតគិតថ្លៃក្នុងរយៈពេលប៉ុន្មាននាទី ប៉ុន្តែជម្រើសមានច្រើនរហូតដល់ការសម្រេចចិត្តខ្លួនឯងក្លាយជាបញ្ហា៖ ប្រភពណា? កម្រិតណា? ទម្រង់ណា?

មេរៀននេះជាមគ្គុទ្ទេសក៍ជាក់ស្ដែងសម្រាប់ការទាញយករូបភាព៖ ប្រភពសំខាន់ៗ ភាពខុសគ្នារវាងផលិតផល របៀបស្វែងរកប្រកបដោយប្រសិទ្ធភាព និងរបៀបចាត់ចែងឯកសារធំៗ។

---

## ៦.១. គោលបំណងសិក្សា

បន្ទាប់ពីបញ្ចប់មេរៀន និស្សិតអាច៖

1. រាយប្រភពរូបភាពបើកចំហ និងពាណិជ្ជកម្មសំខាន់ៗ ព្រមទាំងចំណុចខ្លាំងរបស់នីមួយៗ។
2. បែងចែកកម្រិតផលិតផល (Level 0 ដល់ 3) និងជ្រើសកម្រិតត្រឹមត្រូវសម្រាប់ការងារនីមួយៗ។
3. ប្រើឧបករណ៍ស្វែងរករូបភាព (Copernicus Browser · EarthExplorer) ប្រកបដោយប្រសិទ្ធភាព។
4. អានប្រព័ន្ធតម្កល់ tile របស់ Sentinel-2 និង path/row របស់ Landsat។
5. រៀបចំ និងចាត់ចែងឯកសាររូបភាពសម្រាប់គម្រោងធំ។

## ៦.២. ស្ថានភាពបើកមេរៀន៖ មួយម៉ោងស្វែងរក ដោយមិនទាញយកអ្វីសោះ

និស្សិតម្នាក់ចំណាយពេលមួយម៉ោង ស្វែងរករូបភាពក្នុង Copernicus Browser ដោយប្រើពាក្យគន្លឹះទូទៅ ហើយបញ្ចប់ដោយទាញយករូបភាពខុសកាលបរិច្ឆេទ ដែលមានពពកគ្របដណ្ដប់តំបន់សិក្សាទាំងស្រុង។ បញ្ហាមិនមែននៅឧបករណ៍ទេ គឺនៅ **វិធីស្វែងរក**។

ការស្វែងរករូបភាពប្រកបដោយប្រសិទ្ធភាព ត្រូវការចំណេះដឹងបីយ៉ាង៖ ដឹងថាតំបន់របស់អ្នកស្ថិតក្នុង tile ឬ path/row មួយណា ដឹងពីរបៀបត្រង (filter) តាមលក្ខខណ្ឌច្រើនក្នុងពេលតែមួយ និងដឹងពីរបៀបមើលរូបភាពតូច (preview/quicklook) មុនទាញយកឯកសារពេញ។

សំណួរដែលមេរៀននេះឆ្លើយ៖ មានប្រភពអ្វីខ្លះ ហើយប្រភពនីមួយៗសមស្របនឹងករណីអ្វី? ធ្វើដូចម្ដេចដើម្បីស្វែងរកលឿន និងត្រឹមត្រូវ? ហើយធ្វើដូចម្ដេចដើម្បីចាត់ចែងឯកសាររាប់សិបកុំឲ្យច្របូកច្របល់?

---

## ៦.៣. ទ្រឹស្ដីស្នូល

### ៦.៣.១. ផែនទីនៃប្រភពរូបភាព

ប្រភពរូបភាពបែងចែកជាបួនក្រុមធំ តាមអ្នកផ្ដល់ និងលក្ខខណ្ឌប្រើប្រាស់៖

| ក្រុម | ឧទាហរណ៍ | លក្ខខណ្ឌ |
|---|---|---|
| **ភ្នាក់ងាររដ្ឋបើកចំហ** | Copernicus (Sentinel) · USGS (Landsat) · NASA (MODIS VIIRS) | ឥតគិតថ្លៃទាំងស្រុង · ត្រូវការគណនី |
| **ពាណិជ្ជកម្មគុណភាពខ្ពស់** | Maxar · Planet · Airbus | គិតថ្លៃតាមផ្ទៃ ឬជាវប្រចាំខែ |
| **វេទិកាវិភាគពពក** | Google Earth Engine · Microsoft Planetary Computer | ចូលប្រើទិន្នន័យបើកចំហដោយឥតគិតថ្លៃ តាមរយៈកូដ (សៀវភៅទី៤) |
| **ស្រទាប់មូលដ្ឋាន (basemap)** | Google Satellite · Bing · ESRI World Imagery | ចម្រុះកាលបរិច្ឆេទ · មិនអាចទាញយកជាទិន្នន័យវិភាគ |

ចំណុចសំខាន់ដែលនិស្សិតច្រឡំញឹកញាប់៖ **ស្រទាប់មូលដ្ឋាន** ដូចរូបភាពក្នុង Google Maps ស្អាត និងលម្អិត ប៉ុន្តែជា **ការចម្រុះកាលបរិច្ឆេទច្រើនឆ្នាំ** ដោយគ្មានកាលបរិច្ឆេទច្បាស់លាស់ក្នុងក្រឡានីមួយៗ។ វាល្អសម្រាប់ផ្ទៀងផ្ទាត់ដោយភ្នែក ប៉ុន្តែ **មិនអាចប្រើសម្រាប់ការវិភាគវិទ្យាសាស្ត្រ** ដូចជាការគណនាសន្ទស្សន៍ ឬការចាត់ថ្នាក់ទេ ព្រោះគ្មានកាលបរិច្ឆេទ និងគ្មានក្រុមរលកឆៅ។

### ៦.៣.២. Sentinel-2 លម្អិត

**Copernicus Data Space Ecosystem** ជាច្រកចូលផ្លូវការសម្រាប់ទិន្នន័យ Sentinel។ ចំណុចសំខាន់ដែលត្រូវយល់៖

- **ប្រព័ន្ធ tile**៖ ពិភពលោកបែងចែកជាក្រឡាចត្រង្គ ១០០ × ១០០ គម តាមប្រព័ន្ធ **MGRS** (Military Grid Reference System)។ កម្ពុជាស្ថិតក្នុង tile ចាប់ផ្ដើមដោយ `48P` និង `48Q`។ ការស្គាល់លេខ tile របស់តំបន់អ្នក សន្សំពេលស្វែងរកយ៉ាងច្រើន។
- **Processing baseline**៖ ក្បួនដំណើរការរូបភាពត្រូវបានធ្វើបច្ចុប្បន្នភាពពីមួយកាលទៅមួយកាល (ដូចជា N0511)។ Baseline ចាប់ពី 04.00 មានតម្លៃ **offset** ដែលត្រូវដកចេញ ដូចបានឃើញក្នុង[លំហាត់ទី២](../workbook/lab-02.md)។
- **Relative orbit (R-number)**៖ លេខគន្លងដែលកំណត់ថ្ងៃថ្មីជាក់លាក់ ក្នុងវដ្ដ ១០ ថ្ងៃ។ tile តែមួយអាចមានលេខគន្លងខុសគ្នា អាស្រ័យលើផ្កាយរណប 2A ឬ 2B។

**Semi-Automatic Classification Plugin (SCP)** ក្នុង QGIS អាចស្វែងរក និងទាញយក Sentinel-2 ដោយផ្ទាល់ពី QGIS ដោយមិនចាំបាច់ចេញទៅកម្មវិធីអង្គុយផ្សេង។

### ៦.៣.៣. Landsat និងបណ្ណសារវែង

**USGS EarthExplorer** និង **LandsatLook** ជាច្រកចូលសម្រាប់ Landsat។ ចំណុចខុសពី Sentinel-2៖

- Landsat ប្រើប្រព័ន្ធ **Path/Row** មិនមែន MGRS tile ទេ។ Path គឺជាលេខគន្លង (១ ដល់ ២៣៣) ហើយ Row គឺជាចំណុចតាមទទឹង។ កម្ពុជាភាគច្រើនស្ថិតក្នុង Path ១២៦ ដល់ ១២៧។
- **Collection 2** ជាការដំណើរការឡើងវិញចុងក្រោយបំផុតរបស់ Landsat ទាំងមូល (រួមទាំងរូបភាពចាស់ៗពីទសវត្សរ៍ ១៩៧០)។ ជានិច្ចជ្រើស Collection 2 មិនមែន Collection 1 ចាស់ទេ។
- ការជ្រើសរវាង Landsat 5 (១៩៨៤–២០១៣) Landsat 7 (១៩៩៩–បច្ចុប្បន្ន ប៉ុន្តែមានឆ្នូតបាត់ទិន្នន័យចាប់ពី ២០០៣) និង Landsat 8/9 (២០១៣–បច្ចុប្បន្ន) អាស្រ័យលើឆ្នាំដែលត្រូវការ។

### ៦.៣.៤. ការស្វែងរកប្រកបដោយប្រសិទ្ធភាព

ជំហានស្វែងរកដែលសន្សំពេល៖

1. **កំណត់តំបន់ជាមុន**៖ ស្គាល់លេខ tile ឬ path/row របស់អ្នក ដើម្បីកុំចាំបាច់ត្រូវរុករកគែមទាំងអស់។
2. **ត្រងតាមកាលបរិច្ឆេទ និងពពកជាមុនសិន**៖ កំណត់ជួរកាលបរិច្ឆេទដែលសមហេតុផលសម្រាប់សំណួររបស់អ្នក (ឧ. ខែធ្នូ ដល់ ខែកុម្ភៈ) និងកំណត់ពពកអតិបរមា ២០ ទៅ ៣០%។
3. **មើល preview មុនទាញយក**៖ ប្រព័ន្ធភាគច្រើនបង្ហាញរូបភាពតូចដោយឥតគិតថ្លៃ។ ត្រួតពិនិត្យថាតំបន់សិក្សារបស់អ្នកគ្មានពពក មិនមែនមើលតែភាគរយសរុបទេ។
4. **ពិនិត្យទិសដៅព្រះអាទិត្យ**៖ រូបភាពដែលថតជិតព្រះអាទិត្យអុបទិត្យ (near-nadir) មានស្រមោលតិចជាង។
5. **កត់ត្រា ID រូបភាពភ្លាមៗ**៖ កុំពឹងលើការចាំ ព្រោះឈ្មោះឯកសារវែង និងស្រដៀងគ្នា។

    ប្ដូរលក្ខខណ្ឌទាំងបួន ហើយសង្កេតការណែនាំប្ដូរតាម។ សាកល្បងកំណត់ «វត្ថុតូចបំផុត» ទៅជាអគារ ហើយមើលថាមានប្រភពណាដែលនៅតែសមស្រប។

### ៦.៣.៥. ការទាញយក និងចាត់ចែងទិន្នន័យ

រូបភាព Sentinel-2 មួយ `.SAFE` ពេញលេញមានទំហំ ៨០០ MB ដល់ ១,២ GB។ ការគ្រប់គ្រងឲ្យបានល្អចាំបាច់៖

- **ទាញយកតែអ្វីដែលត្រូវការ**៖ បើត្រូវការតែបួនក្រុមរលក កុំទាញយកឯកសារពេញ។ Copernicus Browser អនុញ្ញាតឲ្យជ្រើសក្រុមរលកជាក់លាក់។
- **ដាក់ឈ្មោះថតឲ្យប្រព័ន្ធ**៖ ឧទាហរណ៍ `data/S2/2025-01-15_T48PVU/` ដែលមានទាំងកាលបរិច្ឆេទ ទាំងលេខ tile។
- **រក្សាឯកសារមេតាទិន្នន័យ**៖ កុំលុប `MTD_MSIL2A.xml` ឬ `.txt` ព្រោះវាមានព័ត៌មានចាំបាច់សម្រាប់ការកែតម្រូវ។
- **កត់ត្រា log**៖ តារាងសាមញ្ញ (Excel ឬ CSV) កត់ត្រា៖ ថ្ងៃទាញយក · កាលបរិច្ឆេទរូបភាព · ភាគរយពពក · លេខ tile · គោលបំណងប្រើប្រាស់។ វានឹងសន្សំពេលអ្នកយ៉ាងច្រើននៅចុងគម្រោង ពេលត្រូវពន្យល់ថាទិន្នន័យមកពីណា។

!!! tip "អ៊ីនធឺណិតយឺត"
    បើអ៊ីនធឺណិតយឺត សាកល្បង **Sentinel Hub Playground** ឬ **Copernicus Browser** ដែលអនុញ្ញាតឲ្យទាញយករូបភាព JPG/PNG តូចសម្រាប់ការត្រួតពិនិត្យមុនសិន មុននឹងទាញយកទិន្នន័យវិភាគពេញ។

### ៦.៣.៦. សិទ្ធិប្រើប្រាស់ និងការដកស្រង់

ទិន្នន័យ Copernicus (Sentinel) ស្ថិតក្រោមគោលការណ៍ **ចូលប្រើដោយសេរី និងបើកចំហពេញលេញ**។ ទិន្នន័យ USGS Landsat ក៏បើកចំហដែរ។ ទោះជាឥតគិតថ្លៃ ការដកស្រង់ត្រឹមត្រូវនៅតែចាំបាច់ក្នុងរបាយការណ៍ និងការបោះពុម្ពផ្សាយ៖

> Contains modified Copernicus Sentinel data [ឆ្នាំ], processed by ESA។
> Landsat imagery courtesy of the U.S. Geological Survey។

ការមិនដកស្រង់ប្រភព មិនមែនល្មើសច្បាប់ធ្ងន់ធ្ងរទេ ប៉ុន្តែជាការខ្វះវិជ្ជាជីវៈ ហើយបំបាត់លទ្ធភាពឲ្យអ្នកអានផ្ទៀងផ្ទាត់ការងាររបស់អ្នក។

## ៦.៤. ឧទាហរណ៍ដែលបានដោះស្រាយ៖ ស្វែងរករូបភាពសម្រាប់ការវាយតម្លៃភ្លើងឆេះព្រៃ

ភ្លើងឆេះកើតឡើងក្នុងខេត្តមួយកាលពី ១០ ថ្ងៃមុន។ យើងត្រូវការរូបភាពមុន និងក្រោយភ្លើងឆេះ។

### ជំហានទី១៖ កំណត់តំបន់ និងកាលបរិច្ឆេទ

កំណត់ព្រំតំបន់ដែលរងផលប៉ះពាល់ ហើយកំណត់ tile MGRS ដែលគ្របដណ្ដប់វា។ កំណត់ជួរកាលបរិច្ឆេទ៖ ២ សប្ដាហ៍មុនភ្លើងឆេះ និង ២ សប្ដាហ៍ក្រោយ។

### ជំហានទី២៖ ស្វែងរករូបភាព «មុន»

ត្រងក្នុង Copernicus Browser៖ tile ដែលកំណត់ · កាលបរិច្ឆេទចាប់ពី ១៤ ថ្ងៃមុនភ្លើងឆេះ · ពពក < ២០%។ ជ្រើសរូបភាពដែលកាលបរិច្ឆេទជិតបំផុតនឹងថ្ងៃភ្លើងឆេះ ដើម្បីកាត់បន្ថយភាពខុសគ្នាដែលមិនទាក់ទងនឹងភ្លើង។

### ជំហានទី៣៖ ស្វែងរករូបភាព «ក្រោយ»

ត្រងកាលបរិច្ឆេទក្រោយថ្ងៃភ្លើងឆេះ។ ផ្សែងអាចនៅមានរយៈពេលខ្លះ ដូច្នេះជ្រើសរូបភាពដែលមានពពក **និង** ផ្សែងតិចបំផុត ដោយពិនិត្យ preview ដោយផ្ទាល់ (ភាគរយពពកអាចមិនរាប់ផ្សែងផងដែរ)។

### ជំហានទី៤៖ ពិនិត្យភាពស៊ីគ្នា

ប្រៀបធៀបលេខគន្លង (R-number) នៃរូបភាពទាំងពីរ។ បើខុសគ្នា មុំមើលអាចខុសគ្នាបន្តិច ដែលបង្កើតភាពខុសគ្នាតូចមិនទាក់ទងនឹងភ្លើង។ កត់ត្រាចំណុចនេះជាដែនកំណត់នៃការវិភាគ។

### ជំហានទី៥៖ កត់ត្រា និងទាញយក

កត់ត្រា ID រូបភាពទាំងពីរភ្លាមៗក្នុងតារាង log ទាញយកតែក្រុមរលកចាំបាច់ (B4 B8 B12 សម្រាប់សន្ទស្សន៍ភ្លើងឆេះ) ដើម្បីសន្សំពេលទាញយក។

### សេចក្ដីសន្និដ្ឋានដែលសមស្រប

> «ការស្វែងរកប្រកបដោយប្រព័ន្ធ ចាប់ផ្ដើមពីតំបន់ និងកាលបរិច្ឆេទច្បាស់លាស់ រួចត្រង ពិនិត្យ preview និងកត់ត្រា ID ភ្លាមៗ។ ការធ្វើតាមលំដាប់នេះការពារកំហុសទូទៅ ដូចជាការទាញយករូបភាពខុសកាលបរិច្ឆេទ ឬមានពពក។»

!!! warning "អ្វីដែលយើងមិនអាចសន្និដ្ឋាន"
    ការស្វែងរកមិនអាចធានាថានឹងមានរូបភាពគ្មានពពកនៅគ្រប់កាលបរិច្ឆេទដែលត្រូវការទេ។ ក្នុងករណីភ្លើងឆេះក្នុងឧទាហរណ៍នេះ បើគ្មានរូបភាព «មុន» ដែលគ្មានពពកក្នុងចន្លោះពេលនោះ ត្រូវពង្រីកជួរកាលបរិច្ឆេទ ឬប្រើ Landsat ជំនួយ។

Sentinel-2 ប្រើប្រព័ន្ធ tile MGRS និង Landsat ប្រើ Path/Row។ ការស្វែងរកប្រកបដោយប្រសិទ្ធភាព ចាប់ផ្ដើមពីតំបន់ និងកាលបរិច្ឆេទច្បាស់លាស់ ត្រងតាមពពក ពិនិត្យ preview និងកត់ត្រា ID ភ្លាមៗ។ ការចាត់ចែងទិន្នន័យ និងការដកស្រង់ប្រភពជាទម្លាប់វិជ្ជាជីវៈចាំបាច់។

## ៦.៩. សំណួររំលឹក និងវាយតម្លៃ

### ក. សំណួរយល់ដឹង

1. រាយក្រុមធំបួននៃប្រភពរូបភាព ព្រមទាំងឧទាហរណ៍មួយសម្រាប់នីមួយៗ។
2. ហេតុអ្វីស្រទាប់មូលដ្ឋានមិនសមស្របសម្រាប់ការគណនាសន្ទស្សន៍?
3. បែងចែក MGRS tile និង Path/Row។
4. រាយជំហានប្រាំសម្រាប់ការស្វែងរករូបភាពប្រកបដោយប្រសិទ្ធភាព។
5. ហេតុអ្វីត្រូវដកស្រង់ប្រភពទិន្នន័យ ទោះជាវាឥតគិតថ្លៃ?

### ខ. សំណួរអនុវត្តគោលគំនិត

6. អ្នកត្រូវប្រៀបធៀបតំបន់ព្រៃ ២០១០ និង ២០២៥។ ស្នើប្រភពរូបភាព និងហេតុផល។
7. ការស្វែងរករបស់អ្នកបង្ហាញរូបភាពមួយមានពពក ៨% ប៉ុន្តែពេលបើក preview តំបន់សិក្សារបស់អ្នកមានពពកគ្របទាំងស្រុង។ ពន្យល់ថាហេតុអ្វីអាចកើតឡើងបែបនេះ ហើយអ្នកគួរធ្វើអ្វីបន្ទាប់។
8. សរសេរឈ្មោះថត និងឈ្មោះឯកសារដែលអ្នកនឹងប្រើសម្រាប់រៀបចំរូបភាព Sentinel-2 ចំនួន ១២ សន្លឹក លើខេត្តមួយ ក្នុងរយៈពេលមួយឆ្នាំ។
9. សរសេរបន្ទាត់ដកស្រង់ត្រឹមត្រូវសម្រាប់របាយការណ៍ដែលប្រើទាំង Sentinel-2 ទាំង Landsat។
10. ពន្យល់ថាហេតុអ្វីរូបភាពពីរដែលមានលេខគន្លង (R-number) ខុសគ្នា អាចផ្ដល់លទ្ធផលវិភាគខុសគ្នាបន្តិច ទោះជាថតជិតកាលបរិច្ឆេទគ្នា។

### គ. កិច្ចការខ្លី

ជ្រើសព្រឹត្តិការណ៍មួយនៅកម្ពុជា (ទឹកជំនន់ ភ្លើងឆេះ ឬការសាងសង់ថ្មី) ដែលកើតឡើងក្នុងរយៈពេល ២ ឆ្នាំចុងក្រោយ។ ស្វែងរករូបភាព Sentinel-2 «មុន» និង «ក្រោយ» ព្រឹត្តិការណ៍នោះ ដោយធ្វើតាមជំហានប្រាំក្នុងមេរៀន។ កត់ត្រា ID លេខ tile ភាគរយពពក និងលេខគន្លងក្នុងតារាង log។
