# ឧបសម្ព័ន្ធ ខ៖ ទិន្នន័យ និងរូបភាពផ្កាយរណប

សៀវភៅនេះប្រើ **រូបភាពបើកចំហ** ដែលនិស្សិតទាញយកដោយខ្លួនឯង ព្រមទាំងសំណុំទិន្នន័យវ៉ិចទ័រ `Cambodia` ដែលប្រើរួមជាមួយសៀវភៅទី១ និងទី២។

## ១. សំណុំទិន្នន័យវ៉ិចទ័រ Cambodia

[:material-download: ទាញយក Cambodia.zip](https://github.com/khgeo/gis-fundamentals/releases/latest/download/Cambodia.zip){ .md-button .md-button--primary }

ប្រើសម្រាប់កំណត់តំបន់សិក្សា (AOI) ការកាត់រូបភាព ការយកគំរូ និងការវាយតម្លៃភាពត្រឹមត្រូវ។ បញ្ជីស្រទាប់ពេញលេញ៖ [ឧបសម្ព័ន្ធ ខ នៃសៀវភៅទី២](https://khgeo.github.io/gis-fundamentals/appendix/b-cambodia-data/)។

## ២. Sentinel-2 (Copernicus · សហភាពអឺរ៉ុប)

| លក្ខណៈ | តម្លៃ |
|---|---|
| ក្រុមរលក | ១៣ (L1C) · ១២ (L2A · គ្មាន B10) |
| ក្រឡា ១០ ម | B2 (ខៀវ) · B3 (បៃតង) · B4 (ក្រហម) · B8 (NIR) |
| ក្រឡា ២០ ម | B5 · B6 · B7 · B8A (red edge និង NIR ចង្អៀត) · B11 · B12 (SWIR) |
| ក្រឡា ៦០ ម | B1 (aerosol) · B9 (ចំហាយទឹក) · B10 (cirrus · L1C តែប៉ុណ្ណោះ) |
| ទទឹងថត | ២៩០ គម |
| មកម្ដងទៀត | ប្រហែល ៥ ថ្ងៃ (ផ្កាយរណបពីរ) |
| ទំហំ tile | ១០០ × ១០០ គម · CRS UTM/WGS 84 |
| កម្រិតផលិតផល | **L1C** = ការចាំងផ្លាតកំពូលបរិយាកាស (TOA) · **L2A** = ការចាំងផ្លាតផ្ទៃដី (BOA · កែបរិយាកាសរួច) |

**របៀបទាញយក**៖

1. បង្កើតគណនីឥតគិតថ្លៃនៅ [Copernicus Browser](https://browser.dataspace.copernicus.eu/)។
2. រកតំបន់ → Search → Sentinel-2 → L2A → កំណត់ចន្លោះកាលបរិច្ឆេទ និង cloud cover < ១០%។
3. ទាញយកជា `.SAFE` ឬទាញយកតែក្រុមរលកដែលត្រូវការ។

កម្មវិធីជំនួយ QGIS **Semi-Automatic Classification Plugin (SCP)** អាចស្វែងរក និងទាញយកបានផងដែរ។

!!! tip "រដូវ និងពពក"
    នៅកម្ពុជា រូបភាពគ្មានពពកភាគច្រើនស្ថិតក្នុង **ខែធ្នូ ដល់ខែមីនា**។ ក្នុងរដូវវស្សា ត្រូវពិចារណារ៉ាដា Sentinel-1។

## ៧. ទិន្នន័យគំរូក្នុងសៀវភៅ

ពិសោធន៍អន្តរកម្មភាគច្រើនក្នុងសៀវភៅនេះប្រើ **ទិដ្ឋភាពគំរូសំយោគ** ២០០ × ២០០ ក្រឡា ដែលមានតម្លៃចាំងផ្លាតប្រហាក់ប្រហែលនឹង Sentinel-2 សម្រាប់ទឹក ព្រៃឈើ ស្រែ តំបន់សាងសង់ និងដីទទេ។ វាប្រើសម្រាប់បង្រៀនតែប៉ុណ្ណោះ មិនមែនជាទិន្នន័យពិតទេ។

ពិសោធន៍មួយចំនួនប្រើ **ទិន្នន័យផ្កាយរណបពិត**៖

| ទិន្នន័យ | ប្រភព | ប្រើក្នុង |
|---|---|---|
| ក្រឡាចត្រង្គ MGRS និង Path/Row លើកម្ពុជា | Sentinel-2 · Landsat (ផលិតដោយនិស្សិត/គ្រូបង្រៀន) | [មេរៀនទី៦](../lessons/lesson-06.md) |
| ឯកសារមេតាទិន្នន័យ Landsat 8 ពិត (Path 126 · Row 52) | USGS (`LC08_L1TP_126052_20190211`) | [មេរៀនទី៦](../lessons/lesson-06.md) |
| រូបភាព Sentinel-2 លើក្រុងព្រះសីហនុ ២០១៥ និង ២០២១ | Copernicus (ដំណើរការតាមរយៈ Google Earth Engine) | [មេរៀនទី១៤](../lessons/lesson-14.md)៖ ករណីសិក្សាពិត |

ក្រុមហ្គេនចុងក្រោយ (ព្រះសីហនុ) បង្ហាញការអភិវឌ្ឍឆ្នេរសមុទ្រពិតប្រាកដ ដោយប្រើ Change Vector Analysis នៅលើក្រុមរលកជាច្រើន។ ទិន្នន័យត្រូវបានបំពាញកម្រិតពណ៌ និងបំប្លែងទៅជា ៨ ប៊ីតសម្រាប់ការបង្ហាញលើគេហទំព័រ ដូច្នេះមិនគួរប្រើសម្រាប់ការគណនាត្រឹមត្រូវខ្ពស់ទេ។ លំហាត់ទាំងអស់ (សៀវភៅអនុវត្ត) ប្រើរូបភាពពិតដែលនិស្សិតទាញយកដោយខ្លួនឯង។
