# ឧបសម្ព័ន្ធ ក៖ ការដំឡើង QGIS

!!! warning "ស្ថានភាព៖ គ្រោង"
    ខ្លឹមសារលម្អិត និងរូបភាពអេក្រង់កំពុងរៀបចំ។

## កំណែណែនាំ

សៀវភៅនេះប្រើ **QGIS 3.34 LTR (Long Term Release)** ។ សូមជ្រើសរើស LTR ជានិច្ច
សម្រាប់ការបង្រៀន ព្រោះវាមានស្ថិរភាព និងមិនប្ដូររូបរាងកណ្ដាលឆមាស។

ទាញយក៖ <https://qgis.org/download/>

## តម្រូវការប្រព័ន្ធអប្បបរមា

| ធាតុ | អប្បបរមា | ណែនាំ |
|---|---|---|
| ប្រព័ន្ធប្រតិបត្តិការ | Windows 10 / macOS 11 / Ubuntu 20.04 | ថ្មីជាង |
| RAM | ៤ GB | ៨ GB ឡើងទៅ |
| ទំហំថាស | ២ GB (កម្មវិធី) | ១០ GB (រួមទិន្នន័យ) |

## ជំហានដំឡើង

*(ជំហានលម្អិតតាមប្រព័ន្ធនីមួយៗ, កំពុងសរសេរ)*

## កម្មវិធីបន្ថែម (Plugins) ត្រូវការ

| Plugin | ប្រើក្នុងលំហាត់ | គោលបំណង |
|---|---|---|
| QuickOSM | ៧ | ទាញទិន្នន័យ OpenStreetMap |
| QuickMapServices | ច្រើន | ផែនទីមូលដ្ឋាន |
| qgis2web | ១៤ | បោះផ្សាយផែនទីវេប |
| Semi-Automatic Classification | ១១ (ស្រេចចិត្ត) | ដំណើរការរូបភាពផ្កាយរណប |

ដំឡើងតាម៖ `Plugins → Manage and Install Plugins…`

## ការកំណត់ភាសា និងអក្សរខ្មែរ

QGIS មិនទាន់មានចំណុចប្រទាក់ជាភាសាខ្មែរពេញលេញទេ។ សូមប្រើចំណុចប្រទាក់ជាភាសាអង់គ្លេស
ដែលត្រូវនឹងឈ្មោះឧបករណ៍ក្នុងសៀវភៅនេះ។

សម្រាប់ **ស្លាកឈ្មោះជាអក្សរខ្មែរលើផែនទី** សូមដំឡើងពុម្ពអក្សរមួយក្នុងចំណោមនេះ៖

- **Noto Sans Khmer**, ណែនាំ (ឥតគិតថ្លៃ, តម្រៀបជើងអក្សរត្រឹមត្រូវ)
- **Khmer OS Battambang**, ស្តង់ដារឯកសារសាលា
- **Khmer OS Muol Light**, សម្រាប់ចំណងជើងផែនទី

!!! warning "បញ្ហាទូទៅ"
    បើស្លាកឈ្មោះខ្មែរបង្ហាញជាប្រអប់ ☐☐☐ មានន័យថាពុម្ពអក្សរមិនទាន់ដំឡើង។
    បើជើងអក្សរលោតខុសកន្លែង សូមប្ដូរទៅ **Noto Sans Khmer**។

## ការរៀបចំថតគម្រោង

```
gis-course/
├── data/          # ទិន្នន័យដើម, កុំកែ
├── working/       # ទិន្នន័យកែសម្រួល
├── output/        # ផែនទីនាំចេញ
└── project.qgz    # ឯកសារគម្រោង QGIS
```

សូមប្រើ **ផ្លូវទាក់ទង (relative paths)** ក្នុង QGIS៖
`Project → Properties → General → Save paths: Relative`
ដើម្បីឲ្យគម្រោងនៅតែដំណើរការពេលចម្លងទៅកុំព្យូទ័រផ្សេង។
