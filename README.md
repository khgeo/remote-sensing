# មូលដ្ឋានគ្រឹះនៃការយកព័ត៌មានពីចម្ងាយ

## Fundamentals of Remote Sensing: a Khmer-language textbook (Book 3 of 4)

[![License: CC BY-SA 4.0](https://img.shields.io/badge/License-CC%20BY--SA%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by-sa/4.0/)

A one-semester (15-lesson, 45-hour) undergraduate remote-sensing textbook written **in Khmer**, with a self-study QGIS workbook built on free Sentinel-2, Sentinel-1 and Landsat imagery over Cambodia.

📖 **Read online:** https://khgeo.github.io/remote-sensing/
📚 **The whole series:** https://khgeo.github.io/

| | |
|---|---|
| Lessons | 15 (theory, 3 hours each) |
| Labs | 15 (QGIS practicals with real satellite imagery) |
| Interactive | Simulators built on a synthetic Sentinel-2-like sample scene |
| Software | QGIS 3.34 LTR, free and open source |
| Level | Year 3, Semester 1 · Department of Geography and Land Management |
| License | CC BY-SA 4.0 (imagery: Copernicus / USGS open data) |
